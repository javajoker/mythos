# 路線圖 / Roadmap

| 階段 / Phase | 內容 / Content | 退出條件 / Exit criteria |
|---|---|---|
| **1 山海經 / Shanhaijing** | 資料管線、方法規格、26 段山經重建、海經和大荒經的關係網路、盲候選與多軸擬合 / pipeline, spec, 26 sections, relational network, blind candidates and multi-axis fits | M1–M5（見 PRD / see PRD）；至少 5 份卷宗完成裁決 / ≥ 5 adjudicated dossiers |
| **2 公共層與中文跨語料 / Common layer & Chinese cross-corpus** | 公共層 v1；接入《穆天子傳》《淮南子・地形訓》《尚書・禹貢》《水經》作為 XCP 通道 / common layer v1; ingest these as the XCP channel | 第二部語料只靠兩個適配器即可運行 / a second corpus runs with only two adapters |
| **3 多語種 / Multilingual** | 依序評估：美索不達米亞（吉爾伽美什、埃努瑪・埃利什）、古埃及（亡靈書、金字塔銘文）、吠陀與往世書、希臘（荷馬地理、赫西俄德）、瑪雅（波波爾・烏）/ candidates in order: Mesopotamian, Egyptian, Vedic and Puranic, Greek, Maya | 每新增一個語種，同時加入該語言的文檔版本 / each language added with its doc locale |
| **4 宇宙觀 / Cosmology** | 天文與曆法通道：日月出入之山、星宿、天象紀錄，與天文回推比對 / astronomy and calendar channel: sunrise and sunset mountains, asterisms, sky records vs astronomical retro-calculation | 有一條預先登記的天文預測獲得驗證 / a pre-registered astronomical prediction tested |

**挑選新語料的原則 / Corpus selection**：結構越「資料化」（方位、距離、清單、日期）越優先，因為可以做定量檢驗；有多個獨立見證本的優先。/ the more data-shaped (bearings, distances, lists, dates) the better, since they allow quantitative testing; multiple independent witnesses preferred.
