# Mythos 產品需求文件（PRD）

> 版本 2.0 ・ 2026-10-19 ・ [English](prd.en.md)

## 1. 背景與目標

Mythos 的「產品」有三部分：方法（實體圖譜交叉驗證）、可重現的研究資料庫（文本、知識圖譜、真實世界庫），以及一組 AI 研究代理。目標是讓任何人都能重新產生、檢查、挑戰一部古籍完整而逐條的真實世界對應。

| 目標 | 指標 |
|---|---|
| G1 不遺漏 | 交付涵蓋 100% 的段落與實體提及；未對應的寫明原因 |
| G2 可追溯 | 每個實體、關係、對應都連回條目編號與原句 |
| G3 不繼承結論 | 注疏與前人學說不作為證據；名稱不計分 |
| G4 可信度誠實 | 每個對應都有可信度、級別、支持與違反的關係、其他候選 |
| G5 可重現 | 兩次執行，輸出逐位元組相同 |
| G6 可擴充、多語 | 新語料只需兩個適配器（入庫、實體句式）；每加一種語言就加一個文檔版本 |

## 2. 使用者

| 角色 | 需求 |
|---|---|
| 研究者（人） | 閱讀對應、詢問「X 在哪裡」、挑戰某一條、擴充真實世界庫 |
| AI 研究代理 | 依規格執行抽取、候選、交叉驗證與交付 |
| 審查者／紅隊 | 找反例、誘餌、庫的偏差、被誇大的可信度 |
| 讀者 | 連同可信度與限制閱讀對應 |

## 3. 範圍（第一階段：山海經）

### 3.1 必須（P0）

- **R1 參考語料**：三個公有領域見證本，附來源與重新擷取的腳本。✅
- **R2 結構化條目**：869 段各有可引用的編號。✅
- **R3 校勘**：異文歸屬到條目並分類（草稿政策）；現代移段已登記。✅
- **R4 知識圖譜**：全書每一個實體與關係，覆蓋檢查未解釋為零。✅
- **R5 真實世界庫與候選**：全球地區、水體、動物、文化；每個實體可有多個候選。✅
- **R6 交叉驗證**：聯合求解，附可信度、級別與其他候選；確定性。✅
- **R7 交付**：逐卷、逐段對照，附完整性檢查。✅（初稿 v1）
- **R8 代理與技能**：公共層，加上山海經主持者與 runbook。✅

### 3.2 應該（P1）

- **R9** 庫的平衡（各河流、各地區的資料密度相近）並重跑。
- **R10** 權重敏感度報告。
- **R11** 每一版初稿都經紅隊審查。
- **R12** 為海經、大荒經抽取更多關係（方位、相鄰）。

### 3.3 可以（P2）

- **R13** 互動地圖：對應、可信度與其他候選。
- **R14** 跨語料圖譜（穆天子傳、淮南子・地形訓、禹貢、水經）。
- **R15** 其他語種文本的適配器。

## 4. 功能需求

| ID | 需求 | 驗收 |
|---|---|---|
| F1 | 入庫 | `ingest.py` 產生 `entries.jsonl`，每段一筆 |
| F2 | 校勘 | `collate.py`、`align_witness.py`、`classify_variants.py` 產生異文表、工作文本與移段登記 |
| F3 | 抽取 | `kg_extract.py` 寫出節點、邊、提及、GraphML 與覆蓋檢查；無實體段落 0、未解釋的名稱句式 0 |
| F4 | 候選 | `kg_candidates.py` 為每個可對應的實體給出候選與自身分數 |
| F5 | 交叉驗證 | `kg_crossval.py` 寫出對應，附可信度、級別、支持與違反的關係、樣本中的其他候選 |
| F6 | 交付 | `kg_deliver.py` 寫出逐段檔案；寫入的段落數與提及數不等於原書就失敗 |

## 5. 非功能需求

- **可重現**：只用 Python 標準庫，`python3 -I`，固定種子，輸出排序。
- **中立**：真實世界庫在計分前提交；權重修改要有一般性的理由，並套用到全書。
- **授權**：程式與文檔 Apache-2.0；古籍為公有領域；維基文庫轉錄依 CC BY-SA 4.0 標示。

## 7. 風險

| 風險 | 對策 |
|---|---|
| 庫的偏差（資料詳細的地區或河流吸引對應）| 平衡檢查、唯一性懲罰、未知取基準率 |
| 抽取錯誤產生假關係 | 覆蓋檢查、附例句的「已解釋」類別、對照原文抽查 |
| 多峰解 | 多條鏈、區塊調整、重解的穩定度；「暫定」級別 |
| 過度解讀弱結果 | 每張表都標級別；README 措辭對照級別檢查 |
| 底本含現代編者改動 | 多見證本對勘；工作文本依最早見證本的次序 |
