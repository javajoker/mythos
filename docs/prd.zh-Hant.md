# Mythos 產品需求文件（PRD）

> 版本 0.1 ・ 2026-10-19 ・ [English](prd.en.md)

## 1. 背景與目標

Mythos 的「產品」由三部分組成：一套研究方法、一個可重現的研究資料庫，以及一組 AI 研究代理。目標是讓任何研究者，無論是人還是 agent，都能對一部古籍提出假說、按統一流程檢驗，並得到分級、可追溯、可重測的結論。

| 目標 | 衡量指標 |
|---|---|
| G1 每個結論都可追溯 | 100% 的發現（finding）都引用條目編號和原文；推理鏈可由腳本或檢查清單重現 |
| G2 不繼承既有結論 | 所有外部學說都以 `H-ext-*` 的形式登記；證據表中，「前人說法」不能成為證據 |
| G3 方法可執行 | 研究方法規格中的每個階段，都有對應的 skill 或腳本，以及可勾選的關卡 |
| G4 可擴展到其他古籍 | 新語料只需實現「匯入＋結構抽取」兩個適配器，就能重用公共層 |
| G5 多語言 | 核心文檔有繁體中文和英文；新增其他語種的古籍時，加入該語言版本 |

## 2. 使用者

| 角色 | 需求 |
|---|---|
| 研究者（人） | 提出假說，查看證據和反證，進行裁決 |
| AI 研究代理 | 按規格執行校勘、抽取、擬合和比對；產出結構化的證據紀錄 |
| 審查者 / 紅隊 | 尋找反例、檢查校改預算、做敏感度分析 |
| 讀者 | 閱讀分級結論，以及每條結論的理由和不確定性 |

## 3. 範圍（第一階段：山海經）

### 3.1 必須有（P0）

- **R1 參考語料**：在 `reference/shanhaijing/` 收錄至少三個公有領域見證本；記錄來源、授權和擷取方式；提供重新擷取的腳本。✅
- **R2 結構化條目**：全書 18 卷逐段給出可引用的編號（`SHJ-BB-S-EEE`），保留注疏、異文和現代編者註。✅
- **R3 校勘**：產出見證本異文表，每條異文都可以分類為：異體、訛誤、實質異文、錯簡。⏳（機器對勘已完成，人工分類待做）
- **R4 路線抽取**：抽取五藏山經的站點、方位、里程、水系、生物，並做篇末總數的自洽檢查。✅（首版）
- **R5 研究方法規格**：完成 S0–S9 階段、證據分級、錯誤模型、校改預算和裁決規則。✅
- **R6 假說卷宗**：提供卷宗模板和檢查清單；完成首個卷宗 H-0001。✅
- **R7 Agent 與 Skill**：提供山海經專用的 agent 和 skill，並抽取公共層。✅（首版）

### 3.2 應該有（P1）

- **R8** 鏈條擬合工具：根據錨點和誤差模型做蒙地卡羅投影。✅
- **R9** 水系拓撲圖：全書的「出／注」關係圖，並檢查一致性。
- **R10** 海經、大荒經的相對方位網路：抽取「A 在 B 東」一類關係。
- **R11** 生物特徵指紋：統一描述條目中的生物形態和習性，並與分類群的特徵庫比對。
- **R12** 地理與生物資料適配：DEM、水系、GBIF、古氣候。

### 3.3 可以有（P2）

- **R13** 互動地圖（多假說疊加、殘差可視化）
- **R14** 跨語料：《穆天子傳》、《淮南子・地形訓》、《禹貢》、《水經》
- **R15** 其他語種古籍適配器

## 4. 功能需求

| 編號 | 需求 | 驗收標準 |
|---|---|---|
| F1 | 匯入 | `tools/shj/ingest.py` 產生 `entries.jsonl`，每段一筆，零殘留標記 |
| F2 | 校勘 | `collate.py` 輸出異文表和摘要；異文都歸屬到某個條目 |
| F3 | 抽取 | `extract_routes.py` 輸出站點、篇段和自洽報告 |
| F4 | 擬合 | `chain_fit.py` 給定錨點後，輸出每站的預測座標和 90% 半徑 |
| F5 | 卷宗 | 每個假說目錄都有 `dossier.md`，並通過 [檢查清單](../projects/shanhaijing/docs/checklist.md) 的全部關卡 |
| F6 | 發現 | `findings/F-*.md` 註明信心等級、依據的假說和可撤回條件 |

## 5. 非功能需求

- **可重現**：腳本只用 Python 標準庫，用 `python3 -I` 執行；所有隨機過程都固定種子。
- **可追溯**：任何衍生資料都可以從 `reference/` 加上腳本重新產生。
- **中立性**：規格和 agent 提示詞中都禁止「先選結論」；紅隊是必經環節。
- **授權**：代碼和文檔使用 Apache-2.0；古籍原文屬公有領域；維基文庫轉錄依 CC BY-SA 4.0 註明出處。

## 7. 風險

| 風險 | 緩解措施 |
|---|---|
| 確認偏誤（只找支持的證據） | 預先登記、強制對立假說、紅隊 agent、基準率校正 |
| 過度校改 | 校改預算，每次校改都計入卷宗 |
| 底本含現代編者的改動 | 多見證本對勘；工作文本以最早的見證本為序 |
| 外部事實錯誤 | 外部事實必須附來源，否則標為 `needs-citation`，不計分 |
| 里程單位不確定 | 不預設「里」的長度，由文本內部錨定，或作為蒙地卡羅參數 |
