# Mythos 產品需求文件 v4（PRD）

> 版本 4.0 · 2026-10-21 · [English](prd.en.md)

## 1. 產品與目標

Mythos 的產品包括：迭代時代語義方法、可重現研究資料庫，以及一組分工明確的 AI 研究代理。目標是讓任何人都能重新產生、檢查和挑戰一部古籍與其時代世界的逐條對應。

| 目標 | 驗收指標 |
|---|---|
| G1 不遺漏 | 所有段落與實體提及都有記錄；未對應與未決項有原因 |
| G2 可追溯 | 實體、屬性、關係、判斷和裁決均連回條目與原句 |
| G3 不繼承結論 | 注疏不進入原文證據；現實對應以遮蔽候選競爭產生 |
| G4 合乎時代 | 候選在 4000–1000 BCE 窗口內存在或可見，附年代與狀態 |
| G5 可信度誠實 | 對應附對立候選、證據、可信度與反例；未知不填假分數 |
| G6 可重現 | 來源有快照雜湊，工具輸出可重跑，判斷有輸入雜湊 |
| G7 可擴展 | 新 predicate 按實體類型註冊；公共 agent/skill 不含語料答案 |

## 2. 使用者

- **研究者**：查看每個對應的證據、競爭候選和限制，提出新假說。
- **AI 研究代理**：建立文本圖、時代世界、語義判斷、圖譜與草稿。
- **審查者／紅隊**：尋找反例、洩漏、誘餌失敗、年代錯誤和過度措辭。
- **讀者**：按可信度閱讀對照與地圖，不把示意圖當測量證明。

## 3. 第一版範圍與功能需求

| ID | 需求 | 驗收 |
|---|---|---|
| R1 原文 | 三個見證本、869 條穩定 ID、快照 manifest、明成化本次序與讀法狀態 | 本地快照可核雜湊；正式證據只用已確認讀法 |
| R2 文本事實圖 | 從 working text 抽取實體、提及、名稱語義與文本關係 | 每段有覆蓋結果；未抽取項非隱藏 |
| R3 時代世界 | 有年代、狀態、來源的地理、動物、文明與造物卡 | 窗口外候選排除；同類候選對稱收錄 |
| R4 全量水體映射與語義擬合 | 先由 LLM 為全部水體建立映射並由發起人確認，再依原文→靜態形狀→古代通用詞義→同時代候選→對稱評估，至少三個候選、兩個大區並保留多樣本 | 水體無遺漏且保留共享與歷史狀態；無對立候選不得接受；現代水流、後世地名、傳播鏈缺失和現代狹窄分類不得單獨否決；有洩漏與誘餌檢查 |
| R5 初版圖譜 | `nodes/mentions/edges/attributes` 與類型化 ontology | schema、引用、類型和第一版地理約束通過 |
| R6 迭代草稿 | 五臧山經草稿→屬性補充→後續卷→圖譜更新 | 每條區分原文、候選和未決項，不強求定論 |
| R7 LLM 衝突裁決 | 合併、拆分、異文與修訂由 LLM 附證據決定 | 程序只發現和執行；人工 > LLM > 自動提議 |
| R8 交付 | `deliverables/draft-v1/`、對照、衝突日誌與重建地圖 | 完整性、敏感度和紅隊通過後才發布 |

### 第一版專用約束

- 卷一至五是唯一新地理節點來源；卷六至十八的 `MTN/WAT/LND` 必須復用，未決者為 `pending_anchor`。
- 比例尺在 **0.35–0.42 km/里** 內擬合並做敏感度分析。
- 各篇先獨立，跨篇連接需要文本或已接受關係；總里程不直接等於跨度。
- 未確認候選可作初始化錨點，但沒有證據優先權；迭代校準後，觀察原點才由共同地標形成共識並以穩定 ID 登記。

## 4. 非功能需求

- **分層**：`textual`、`semantic_fit`、`associative`、`deductive` 不混為一談。
- **語義擴展**：predicate 按實體類型註冊，值有證據、狀態與來源。
- **可重現**：Python 標準庫，Python 3.9+，`python3 -I`，輸出排序，判斷按輸入雜湊快取。
- **中立**：今名與名氣不是證據；同類候選採相同容錯和評分規則。
- **授權**：程式與文檔 Apache-2.0；古籍公有領域；Wikisource 轉錄 CC BY-SA 4.0。

## 6. 風險與對策

| 風險 | 對策 |
|---|---|
| 預設答案污染判斷 | 遮蔽、對立候選、洩漏探測、誘餌與紅隊 |
| 語義比對無限遷就 | 罕見特徵、關係約束、反例、敏感度與可證偽測試 |
| 時代庫偏斜 | 同類候選對稱收錄，檢查資料詳度 |
| 把文本事實與推論混合 | 屬性 kind/status 與獨立來源記錄 |
| 程序取代語義裁決 | 程序只檢測與執行，LLM 裁決並可被人覆核 |
| 過度解讀弱結果 | 可信度分級，未知留空，暫定不作定論 |
