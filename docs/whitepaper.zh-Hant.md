# Mythos 白皮書：把古籍放回它形成的那個世界

> 版本 4.0 · 2026-10-21 · [English](whitepaper.en.md)

## 摘要

人類最早的文字中，有些被歸入神話、傳說或志怪。它們可能包含想像，也可能保存變形後的真實觀測。Mythos 把它們視為傳承紀錄：抽取實體、描述與關係，重建其時代世界，再以可重現的方式比較競爭對應。

第一個研究對象是 **《山海經》**，第一版時代窗口為 **4000–1000 BCE**。我們不預設它只記錄中國，也不預設它必然描述全球；每一個現實對應都必須與對立候選一起接受檢驗。

## 1. 要解決的問題

1. **先有結論**：把文本遷就既定答案。
2. **用錯時代地圖**：忽略海岸、河道、氣候、動物與造物的時代差異。
3. **以名為證**：用今名相似或單一醒目特徵代替完整證據。
4. **事實與推論混合**：原文陳述、語義擬合、文化聯想和演繹推論沒有分層。
5. **無法重現**：來源、判斷、衝突裁決和生成過程沒有留下記錄。

## 2. 方法：迭代時代語義對應

| 階段 | 內容 |
|---|---|
| 工作文本 | 多見證本校勘，固定條目 ID，分離注疏，記錄讀法狀態 |
| 實體抽取 | 建立文本事實圖，保留名稱語義和未決提及 |
| 地理語義擬合 | 名稱遮蔽下提出競爭候選，逐屬性評分並保留判斷 |
| 初版圖譜 | 結合文本事實與有來源的語義擬合屬性 |
| 底層卷草稿 | 逐條區分原文、候選解釋與未決項 |
| 屬性補充 | 加入聯想和演繹屬性，不冒充原文事實 |
| 後續卷與更新 | 完成後續文本並更新實體、復用和錨定關係 |
| 衝突與迭代 | 程序發現，LLM 裁決；重跑受影響產物 |
| 審查與交付 | 對立候選、敏感度、洩漏與紅隊通過後，生成對照和示意地圖 |

所有實體遵循同一推論順序：**原文證據 → 靜態形狀與物理特徵 → 古代通用詞義 → 同時代候選 → 對稱評估 → 可信度與未知項**。動態水流只保留為原文線索，候選比較可降為無方向連接；後世地名、現代分類、傳播鏈缺失不得提前否決或鎖定答案。文化歷史機制未知時不得編造。

《山海經》第一版另要求卷六至十八的地理提及復用《五臧山經》節點。這只限制圖譜結構，不預定現實對應。里數在 0.35–0.42 km/里區間擬合，各篇先獨立；跨篇連接需要證據。

## 3. 可審查的技術分工

程序負責來源快照、結構校驗、文本定位、數值計算、覆蓋和衝突發現。LLM 負責語義抽取、候選評分、異文與解釋裁決、合併或拆分，以及指定草稿修訂。人工覆核高於 LLM，LLM 高於自動提議。

每個判斷保留模型、提示版本、樣本、輸入雜湊、證據和理由。輸入不變不重判，相同資料應生成相同結果。

## 5. 範圍

第一階段完成《山海經》迭代時代語義版；之後才把公共層用於其他中文語料和多語種文本。天文與曆法對應同樣需要競爭候選和時代證據。見 [路線圖](roadmap.md)。

## 6. 不做的事

- 不把任何地區或具體對應預設為答案。
- 不以今名、名氣或單一相似點比定。
- 不把跨篇里程總和直接當地理跨度。
- 不用程序啟發式代替 LLM 的語義裁決。
- 不把覆蓋率或高相似度寫成已證實結論。
