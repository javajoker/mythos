# Mythos 白皮書：把古籍逐個實體對應到真實世界

> 版本 2.1 ・ 2026-10-19 ・ [English](whitepaper.en.md)

## 摘要

人類最早的文字，有許多今天被歸入「神話」「傳說」「志怪」。其中有些是純粹的想像，也有些可能是**變形了的真實觀測**：在口傳、重繪、傳抄與翻譯之中失去原有參照系的地點、河流、物種與人群紀錄。Mythos 把這樣的文本當作一張**知識圖譜**：它提到的每一個實體、它對每個實體的描述、實體之間的關係。然後在整個地球上尋找真實世界的候選，讓關係去**交叉驗證**這些候選，最後得到全書逐條的對應，每一條都附可信度。

第一個研究對象是 **《山海經》**。全書 869 段，提到約兩千個山、水、國族、生物、植物與礦物，並以相鄰、水系（「出」「注」）與相對方位把它們連在一起。關係這麼密，正好適合作為檢驗方法的第一個案例。

## 1. 問題

1. **先有結論。** 傳統注疏把全書限定在中原周邊，現代的「山海經即世界地理」之說則反過來；兩者大多先有答案，再挑合用的條目。
2. **以名為證。** 比定常常建立在同名的今地或單一醒目的特徵上，而忽略該實體的其他關係。
3. **一次只看一處。** 孤立地檢驗一個比定，無法知道全書其他部分是否仍然吻合。
4. **無法重現。** 推理散落各處，不能逐步核對。

## 2. 方法：實體圖譜交叉驗證

| 步驟 | 內容 |
|---|---|
| 1. 實體 | 找出全書所有實體，合併異寫與同名 |
| 2. 描述與關係 | 記錄每個實體的描述與性質，以及實體之間的每一條關係，成為附條目編號的知識圖譜 |
| 3. 候選 | 只依描述，在**全球**為每個實體找真實候選（地區、河湖海、動物、古代文化）。**名稱只是符號**，不計分 |
| 4. 交叉驗證 | 同時為所有實體選擇對應，使描述與關係的吻合度最高；以丟棄部分關係的重解測穩定度；可信度 = 穩定度 × (1 − e^(−邊際)) |
| 5. 交付 | 與原書逐條對應：每一段、每個實體、對應與可信度，或未對應的原因；必須通過完整性檢查 |

距離與方位只作小權重的參考；最重要的是結構性的關係，例如哪條水注入哪條水。

## 3. 為什麼是現在

- **古籍已數位化**，而且常有多個獨立見證本（山海經有維基文庫通行本、明成化本、四庫全書本）。
- **世界資料開放**：河網、物種分佈、考古文化都可以整理成真實世界庫。
- **AI 代理**可以在嚴格的規程下完成窮盡的抽取與檢查，每一步都能寫成確定性的腳本。

## 4. 初步結果（山海經初稿 v3）

- **沒有遺漏**：869 段、4,004 次實體提及，全部有對應或原因（[交付](../projects/shanhaijing/deliverables/draft-v3/README.md)）。
- **清楚的結果可能來自有偏差的庫。** 初稿 v1 的「黃河」結果依賴只有中國河流列出支流，審查後撤回（[紅隊](../projects/shanhaijing/docs/red-team.md)）。
- **解讀要檢驗，不是直接採用。** 項目發起人的解讀規則（水只是水體、山只是外觀、時間深度、地圖讀法、方位慣例）對所有候選一體適用；提出的解讀（西山經 = 哈拉帕、蘇美、埃及）被寫成固定組態，與對立組態比較：它低於中國、北美誘餌與衣索比亞組態；但崑崙之丘那一段本身與埃及相容。
- **留下來的**：20 個對應既有足夠可信度又穩健，多為描述特別的動物，加上毛民 → 阿伊努與中國境內少數山。
- **通行數字本不是原文**（[F-0001](../projects/shanhaijing/findings/F-0001-base-text-modern-relocations.md)）。

## 5. 範圍與路線圖

- **第一階段**：山海經：補抽其餘的空間關係，決定新的解讀規則（河流的地圖讀法、時間深度、外觀與行為），並檢驗對立的組態，例如崑崙在埃及。
- **第二階段**：相關中文文本（穆天子傳、淮南子・地形訓、禹貢、水經），以同一方法建圖，跨書共有的實體成為額外的關係。
- **第三階段**：其他語種的文本（美索不達米亞、古埃及、吠陀、希臘、瑪雅），每加一種語言就加一個文檔版本。

## 6. 不做的事

- 不預設答案：既不預設「山海經是全球地理」，也不預設「山海經只講中國」。
- 不以名稱比定。
- 不把結果引用得高於它的可信度級別。
