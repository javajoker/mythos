# Mythos 白皮書：以可證偽方法重讀古籍中的世界與宇宙

> 版本 0.1 ・ 2026-10-19 ・ [English](whitepaper.en.md)

## 摘要

人類最早的文獻中，有大量內容在今天被歸為「神話」「傳說」或「怪誕」。其中一部分確實是想像；但也有一部分可能是**變形了的真實觀測**，例如被口傳、轉繪、轉抄、翻譯多次以後，失去原有參照系的地理、物種、天象或事件記錄。Mythos 要做的，是建立一套**原文優先、多軸交叉、錯誤可建模、結論可證偽**的研究方法，並配備可重現的資料管線與 AI 研究代理，把這些文本放回現有的世界觀（地理、生物、氣候、考古）和宇宙觀（天文、曆法）中逐條檢驗。

第一個研究對象是《山海經》。它是先秦時期成書、結構最「資料化」的古籍之一：五藏山經以「方位＋里程＋山名＋水系＋物產＋生物」的固定格式記錄了 400 多個站點，而海經、大荒經以相對方位描述數百個國族、神祇和地貌。這種結構讓它特別適合用可計算的方法檢驗。

## 1. 問題

1. **結論先行**：無論是傳統注疏把山海經限定在中原周邊，還是現代「山海經即全球地理」之說，都常常先有結論，再挑選支持它的條目。被挑中的條目往往只與某一個特徵相似，比如「人面獸身」對上人面獅身像；整條路線上互相矛盾的資訊卻被忽略。
2. **證據不獨立**：同一個聯想被重複使用，看起來像多重佐證。
3. **校改無代價**：遇到不合的里程或方位，就說是「傳抄錯誤」並隨意修改，使任何假說都能自圓其說。
4. **不可重現**：推理過程散落在書和文章中，無法逐步覆核。

## 2. 方法總覽

Mythos 研究框架（詳見 [research-framework.md](research-framework.md)）由六個支柱構成：

| 支柱 | 內容 |
|---|---|
| **原文與見證本** | 收集多個公有領域版本，逐條建立可引用的編號，保留異文與注疏，但注疏只作為「讀者的說法」 |
| **結構抽取** | 把文本轉為資料：站點、方位、里程、水系拓撲、生物描述、礦產、族群、天象 |
| **內部一致性** | 先用文本自身檢查錯誤：分段里程與篇末總數、河流的源頭與匯流點、方位閉合 |
| **多軸交叉定位** | 幾何擬合、水系拓撲、生物分佈與遷徙、礦產、氣候、族群、天文、跨文本，各自獨立評分 |
| **錯誤模型與校改預算** | 形近字、數字訛誤、錯簡、圖轉文、口傳變形；每次校改都要扣分 |
| **裁決與發佈** | 預先登記、對立假說、紅隊審查、敏感度分析、分級結論，可以撤回、可以重測 |

## 3. 為什麼現在可以做

- **公有領域文本已數字化**：維基文庫已有《山海經》的通行本、四部叢刊（明成化本）和四庫全書本。
- **全球地理與生物分佈資料公開**：例如 DEM 地形、水系網路、GBIF 物種分佈、古氣候重建等，可用來大規模比對「指紋」。
- **AI 代理**：可以在嚴格流程下處理大量繁瑣的比對工作，而人類研究者專注於判斷與裁決。Mythos 為此提供專用 agent 與 skill，並把方法寫成機器可執行的檢查清單。

## 4. 首個案例的啟示

在建立資料管線的第一天，方法本身就發現了兩件事：

1. **通行數字本並非「原文」**：維基文庫通行本按照袁珂等現代校注，把《海內西經》《海內北經》《海內東經》的多段文字搬移了位置，並補入了句子。這些都是現代學者的結論，不是原文。與明成化本對勘後，這些改動已被逐條標出（見 [來源評估](../projects/shanhaijing/docs/source-assessment.md)）。
2. **文本可以自我校驗**：把五藏山經每一段的里程加總，再與篇末的「凡若干山，若干里」比較，可以客觀地找出可能的訛誤位置，例如《中山經》首篇的分段里程只有 937 里，篇末總數卻記為 6670 里。

首個假說卷宗 [H-0001](../projects/shanhaijing/hypotheses/H-0001/dossier.md) 檢驗了「崑崙在埃及、赤水為紅海、黑水為尼羅河、流沙為撒哈拉」這一假說，示範了完整的流程：預先登記、全語料核對、鏈條擬合、基準率分析、對立假說，以及最終的分級裁決。

## 5. 範圍與路線

- **第一階段**：《山海經》。完成資料管線、方法規格、五藏山經全段的幾何與水系重建，以及海經、大荒經的相對方位網路。
- **第二階段**：把可重用的 agent 與 skill 抽取為公共層（已開始），並接入相關中文古籍（例如《穆天子傳》、《淮南子・地形訓》、《禹貢》、《水經》），用作跨文本證據。
- **第三階段**：擴展到其他語言的古籍與神話，例如美索不達米亞、埃及、吠陀、希臘、美洲。每增加一個語種，就在文檔中加入該語言版本。

## 6. 不做什麼

- 不預設任何答案，包括「山海經是全球地理」或「山海經只寫中國」。
- 不把相似當作證據。相似度要經過基準率和獨特性校正。
- 不在沒有登記假說和證偽條件的情況下發佈結論。
