# Mythos 白皮書：把古籍放回它形成的那個世界

> 版本 3.0 ・ 2026-10-20 ・ [English](whitepaper.en.md)

## 摘要

人類最早的文字，有許多今天被歸入「神話」「傳說」「志怪」。其中有些是純粹的想像，也有些可能是**變形了的真實觀測**，經由長期口傳與傳抄保留下來。Mythos 把這樣的文本當作**傳承紀錄**：一組實體（地點、水、人群、生物、器物）、文本對每個實體的描述，以及實體之間的關係。我們重建紀錄積累時期的**當時世界**（海岸線、河道、氣候、動物、文明與其造物），尋找兩者之間最一致的對應。對應由大模型在名稱遮蔽下逐項**語義判斷**，每個判斷都記錄下來，再對全書聯合求解。

第一個研究對象是 **《山海經》**：視為約前 4000–前 2000 年逐步積累的紀錄，從編者的故土中原出發理解。全書 869 段，提到約兩千個山、水、人群、生物與器物，並以路線、水系與相對方位連在一起。

## 1. 問題

1. **先有結論。** 有的解讀把全書限定在某一地區，有的投射到全世界，大多先有答案。
2. **用錯了地圖。** 拿今日的地圖比對古籍，忽略了六千年的變化：海岸、河道、沙漠、動物與建築都不一樣。
3. **以名為證。** 比定常建立在今名或單一醒目的特徵上。
4. **無法重現。** 推理不能逐步核對。

## 2. 方法：時代語義對應

| 步驟 | 內容 |
|---|---|
| 原始文本 | 只用最早的見證本；注疏不進入任何步驟；容許傳抄錯誤並記錄 |
| 實體與關係 | 每個實體、描述、關係，以及名稱所帶的語義（赤 = 紅），名稱不作辨識 |
| 觀察框架 | 方位與里程從編者的原點理解，作為軟約束 |
| 當時世界 | 海岸、河道、氣候、動物（含已滅絕者）、文明與其造物，每項附年代 |
| 語義判斷 | 大模型在遮蔽下提出候選並逐項評分，附證據、理由與多個樣本；以洩漏探測與誘餌防範先入知識 |
| 聯合求解 | 全書最一致的對應與可信度 |
| 交付 | 每一段、每個實體，以及當時的地圖 |

完整方法見 [研究框架](research-framework.md)。

## 3. 為什麼是現在

- 古籍已數位化，常有多個獨立見證本。
- 考古與古地理已足以重建當時的世界。
- 大模型能大量判斷語義相關，而每個判斷都可以記錄與審查。

## 4. 現況

- 山海經的文本層已完成：三個見證本、869 段、明成化本次序；並發現通行數字本默默移動了段落（[F-0001](../projects/shanhaijing/findings/F-0001-base-text-modern-relocations.md)）。
- 知識圖譜涵蓋全書（1,943 個實體、2,741 條關係），覆蓋檢查通過。
- 框架 v3、前 4000–前 2000 年的時代世界、規格、agent 與 skill 已就緒；下一步是西山經試點，之後擴及全書（初稿 v4）。
- 先前版本（在 git 歷史中）的教訓：候選庫若對某一地區較詳細，就會造出清楚但錯誤的結果；所以庫的平衡檢查與「固定組態對對立組態」的檢驗是必做的。

## 5. 範圍與路線圖
第一階段：山海經時代語義版；第二階段：相關中文文本；第三階段：其他語種，共用同一個時代世界；第四階段：天文與曆法。見 [路線圖](roadmap.md)。

## 6. 不做的事
- 不預設地區：既不預設「只講中國」，也不預設「講全世界」。
- 不以今名或名氣比定。
- 不把結果引用得高於它的可信度級別。
