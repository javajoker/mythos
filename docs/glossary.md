# 詞彙表 v4 / Glossary v4

| 繁中 | English | 定義 / Definition |
|---|---|---|
| 見證本 | Witness | 一部文本的獨立版本或轉錄。 |
| 原始快照 | Source snapshot | 保存的見證本檔案及其路徑、大小與 SHA-256，不因上游更新而靜默改變。 |
| 工作文本 | Working text | 按最早見證本次序排列的條目及讀法狀態；只有已確認讀法可作正式證據。 |
| 異文 | Variant | 見證本之間的差異。 |
| 錯簡 | Displacement | 段落或文本單位的錯位。 |
| 替代讀法 | Variant reading | 由見證本或明確錯誤類型支持、經 LLM 或人工裁決的另一讀法。 |
| 條目 | Entry | 可引用的最小文本單位，ID 穩定。 |
| 節點 | Node | 圖譜中的首發實體；名稱、坐標與現代對應不進入 ID。 |
| 提及 | Mention | 實體在某段原文中的一次出現，可尚未連到節點。 |
| 名稱特徵 | Name feature | 名稱中的顏色、材質、形狀、狀態或方位語義，作為低權重描述。 |
| 今名比對 | Modern-name matching | 因今名相似而判為同一對象；禁止作為證據。 |
| 文本事實圖 | Text graph | 原文直接陳述的實體、提及、屬性與關係。 |
| 解釋圖 | Interpretation graph | 語義擬合、聯想、演繹、候選對應與裁決形成的圖譜層。 |
| 屬性斷言 | Attribute assertion | 某實體的一個 predicate/value 記錄，附種類、狀態、證據和來源。 |
| 語義擬合 | Semantic fit | 文本描述與時代候選之間的逐屬性對應判斷。 |
| 時代窗口 | Period window | 文本被視為積累而成的期間；山海經第一版為 4000–1000 BCE。 |
| 時代世界庫 | Era world base | 窗口內的地理、動物、文明與造物，每項附年代、狀態和一般性來源。 |
| 觀察原點 | Observer origin | 由共同可確認地標及其關係反推、經共識登記的觀察基準。 |
| 地標共識 | Anchor consensus | 多個獨立條目和關係共同支持一個錨點後形成的可審查決定。 |
| 遮蔽 | Masking | 判斷時以代號替代名稱，只留描述、名稱特徵與關係。 |
| 對立候選 | Rival | 與重點候選同類、同時期的其他可行候選。 |
| 判斷紀錄 | Judgment record | 一次判斷的輸入雜湊、模型、提示版本、樣本、證據與理由。 |
| 洩漏 | Leakage | 判斷受先入知識或既有比定影響，以遮蔽／不遮蔽差異檢測。 |
| 誘餌 | Decoy | 人工構造的描述，用來檢查模型是否被套向熱門答案。 |
| 聯合一致性 | Joint consistency | 所有實體與關係在同一組態下相互支持的程度。 |
| 固定組態 | Held configuration | 固定一組假說後重新求解其餘部分，用於比較對立解讀。 |
| 可信度 | Confidence | 由判斷一致性、候選邊際、穩定度、敏感度與洩漏共同決定的等級；未知時留空。 |
| 暫定 | Tentative | 可信度低於 0.1 或證據不足，不得作為定論引用。 |
| 完整性檢查 | Completeness check | 段落、提及和交付記錄數相符；只代表覆蓋，不代表正確。 |
| 待錨定 | Pending anchor | 第一版後續卷地理提及尚未由 LLM 連到五臧山經節點的狀態。 |
| 語義衝突 | Semantic conflict | 同一主體或關係存在需要語義判斷的不同解釋；程序只發現，LLM 裁決。 |
| 紅隊 | Red team | 獨立尋找反例、偏差、洩漏、年代錯誤和過度措辭的審查。 |
| 里 | li | 古代長度單位；山海經第一版在 0.35–0.42 km/里區間擬合，並做敏感度分析。 |
| 篇段獨立 | Section independence | 沒有跨篇連接證據時，各篇分別建模；總里程不直接等於地理跨度。 |
