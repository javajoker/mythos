# 詞彙表 / Glossary

| 繁中 | English | 定義 / Definition |
|---|---|---|
| 見證本 | Witness | 一部文本的某個獨立版本或轉錄 / an independent edition or transcription of a text |
| 底本 | Base text | 編號所依據的見證本 / the witness that entry IDs are keyed to |
| 工作文本 | Working text | 校勘後、按最早見證本順序選定讀法的文本 / the collated text in earliest-witness order |
| 異文 | Variant | 見證本之間的差異 / a difference between witnesses |
| 錯簡 | Displacement | 段落或竹簡的錯位 / a misplaced paragraph or bamboo slip |
| 校改 | Emendation | 對文本讀法的修正；需要分類並計算成本 / a change to a reading; typed and costed |
| 校改預算 | Correction budget | 一份卷宗可以使用的校改總成本上限 / the total emendation cost a dossier may spend |
| 條目 | Entry | 可引用的最小文本單位（段）/ the smallest citable unit (paragraph) |
| 站點 | Station | 山經路線中的一座山或一個地點 / one mountain or place on a Mountain-Classic route |
| 篇段 | Section | 山經的一篇，例如「西次三經」/ one Mountain-Classic section, e.g. 西次三經 |
| 通道 | Evidence channel | 獨立的證據來源類別（GEO、HYD…）/ an independent class of evidence |
| 對照集 | Comparison set | 「若假說不成立，還有什麼會產生同樣觀察」的集合 / everything else that would produce the same observation |
| 基準率 | Base rate | 某個特徵在語料或世界上出現的頻率 / how often a feature occurs in the corpus or the world |
| 似然比 | Likelihood ratio (LR) | P(觀察｜H) / P(觀察｜非 H) |
| 預先登記 | Pre-registration | 在檢驗前寫下預測與證偽條件 / writing predictions and falsifiers before testing |
| 指紋 | Fingerprint | 從文本中提取的一組可比對特徵 / a set of matchable features extracted from the text |
| 盲候選生成 | Blind candidate generation | 在不參考前人結論的情況下生成候選地 / generating candidate loci without consulting prior conclusions |
| 鏈條擬合 | Chain fit | 由方位與里程重建路線並投影到地球 / rebuilding a route from bearings and distances and projecting it onto the Earth |
| 水系同構 | Hydrological isomorphism | 文本河流圖與實際水系的結構對應 / structural match between the text's river graph and real drainage |
| 紅隊 | Red team | 專門試圖推翻假說的審查 / review that tries to break the hypothesis |
| 保留的觀察 | Retained observation | 任何框架都必須解釋的文本事實 / a textual fact every frame must explain |
| 虛無假說 | Null hypothesis | 「此處是想像、拼合或圖像衍生」/ "imagined, composite, or picture-derived" |
| 里 | li | 古代長度單位，長度不預設 / ancient length unit, not assumed |
| 出／注／潛 | rises / flows into / sinks | 山海經的水系動詞 / Shanhaijing hydrological verbs |
| 陰／陽 | north / south slope | 山之北／南坡（水則相反）/ north and south slopes of a mountain (reversed for rivers) |
| 流沙 | Flowing / shifting sands | 通名，全書 21 段出現 / generic term, in 21 paragraphs |
