# 詞彙表 / Glossary

> v3.0 ・ 2026-10-20

| 繁中 | English | 定義 / Definition |
|---|---|---|
| 見證本 | Witness | 一部文本的某個獨立版本或轉錄 / an independent edition or transcription |
| 原始古本 | Original text | 本項目可取得的最早完整見證本（山海經：明成化本）的次序與讀法 / the earliest complete witness's order and readings |
| 工作文本 | Working text | 按原始古本次序排列、選定讀法的文本 / the text in that order with chosen readings |
| 異文 | Variant | 見證本之間的差異 / a difference between witnesses |
| 錯簡 | Displacement | 段落或竹簡的錯位 / a misplaced paragraph or slip |
| 替代讀法 | Variant reading | 依見證本或明列的錯誤類型（形近、數字、錯簡）採用的另一讀法，小幅扣分 / an alternative reading from a witness or a stated error type |
| 傳承紀錄 | Transmitted record | 經長期口傳、傳抄而積累的紀錄，含缺失與錯誤 / a record accumulated and copied over a long time |
| 條目 | Entry | 可引用的最小文本單位（段）/ the smallest citable unit |
| 實體 | Entity | 書中提到的一個對象；名稱不作辨識依據 / a thing the text mentions; its name does not identify it |
| 名稱特徵 | Name feature | 名稱中的語義詞（顏色、材質、形狀、狀態、方位），作為較低權重的描述 / semantic words in a name, used as down-weighted description |
| 今名比對 | Modern-name matching | 因候選今日的名稱相似而判定吻合；禁止 / matching by a candidate's modern name; forbidden |
| 知識圖譜 | Knowledge graph | 實體與關係的集合，每條附條目編號 / entities and relations with entry IDs |
| 時代窗口 | Period window | 文本被視為積累而成的期間（山海經：前 4000–前 2000 年）/ the period the text accumulated over |
| 時代世界庫 | Era world base | 窗口內的地理、動物、文明與造物，每項附年代與當時樣貌 / the world of the window, dated |
| 當時樣貌 | State | 候選在窗口內的狀態：存在、廢墟、已消失 / living, ruin, gone |
| 觀察原點 | Observer origin | 理解方位與里程的出發點（山海經：中原）/ where bearings are read from |
| 遮蔽 | Masking | 判斷時把名稱換成代號，只留描述、名稱特徵與關係 / replacing names by codes in judgment tasks |
| 語義判斷 | Semantic judgment | 大模型逐項屬性給出的吻合分數、證據與理由 / attribute-wise scores with evidence and reasons |
| 判斷紀錄 | Judgment record | 一次判斷的完整紀錄（輸入雜湊、模型、提示詞版本、樣本）/ the full record of one judgment |
| 洩漏 | Leakage | 判斷受模型先入知識（注疏、前人比定）影響；以遮蔽與不遮蔽的差異檢測 / prior knowledge steering a judgment |
| 誘餌 | Decoy | 人工編造的描述，用來檢查是否被套到熱門答案 / a synthetic description testing bias |
| 對立候選 | Rival | 與重點候選同時期、同類的其他候選 / another candidate of the same kind and period |
| 對稱 | Symmetry | 每一種寬容與每一類候選都對所有地區一體適用 / every leniency and kind of candidate applies everywhere |
| 聯合求解 | Joint solution | 同時為所有實體選候選，使全書總分最高 / choosing all candidates at once for the best total |
| 固定組態 | Held configuration | 把某個解讀的實體固定在其候選上，其餘重新求解，用來檢驗解讀 / a reading held fixed while the rest is re-solved |
| 穩定度 | Stability | 各次重解中選到同一候選的比例 / share of re-solves agreeing |
| 可信度 | Confidence | 穩定度 × 邊際項 × (1 − 判斷差異) × 洩漏折扣 / stability × margin term × (1 − judgment spread) × leakage discount |
| 暫定 | Tentative | 可信度 < 0.1：不宜引用 / below 0.1: do not cite |
| 完整性檢查 | Completeness check | 交付中段落數與提及數等於原書 / deliverable rows equal the text's paragraphs and mentions |
| 紅隊 | Red team | 專門試圖推翻對應的審查 / review that tries to break the mapping |
| 里 | li | 古代長度單位；比例尺未知，作軟約束 / ancient length unit of unknown scale |
| 出／注／潛 | rises / flows into / sinks | 山海經的水系動詞；依地圖讀法理解 / hydrological verbs, read as map lines |
