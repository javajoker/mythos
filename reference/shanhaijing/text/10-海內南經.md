## 海內南經

<a id="SHJ-10-1-001"></a>**`SHJ-10-1-001`** 海內東南陬以西者。

<a id="SHJ-10-1-002"></a>**`SHJ-10-1-002`** 甌居海中。閩在海中，其西北有山。一曰閩中山在海中。

<a id="SHJ-10-1-003"></a>**`SHJ-10-1-003`** 三天子鄣山在閩西海北。一曰在海中。

<a id="SHJ-10-1-004"></a>**`SHJ-10-1-004`** 桂林八樹在番隅東。

<a id="SHJ-10-1-005"></a>**`SHJ-10-1-005`** 伯慮國、離耳國、雕題國、北朐國皆在鬱水南。鬱水出湘陵南海。一曰相慮。

<a id="SHJ-10-1-006"></a>**`SHJ-10-1-006`** 梟陽國在北朐之西，其為人人面長脣，黑身有毛，反踵，見人笑亦笑；左手操管。

<a id="SHJ-10-1-007"></a>**`SHJ-10-1-007`** 兕在舜葬東，湘水南，其狀如牛，蒼黑，一角。

<a id="SHJ-10-1-008"></a>**`SHJ-10-1-008`** 蒼梧之山，帝舜葬于陽，帝丹朱葬于陰。

<a id="SHJ-10-1-009"></a>**`SHJ-10-1-009`** 氾林方三百里，在狌狌東。

<a id="SHJ-10-1-010"></a>**`SHJ-10-1-010`** 狌狌知人名，其為獸如豕而人面，在舜葬西。

<a id="SHJ-10-1-011"></a>**`SHJ-10-1-011`** 狌狌西北有犀牛，其狀如牛而黑。

<a id="SHJ-10-1-012"></a>**`SHJ-10-1-012`** 夏后啟之臣曰孟涂，是司神于巴，人請訟于孟涂之所，其衣有血者乃執之，是請生。居山上，在丹山西。 ⟨異文 居山上，在丹山西。／居山上，在丹山西。丹山在丹陽南，丹陽居屬也。⟩

<a id="SHJ-10-1-013"></a>**`SHJ-10-1-013`** 窫窳龍首，居弱水中，在狌狌之西，其狀如貙，龍首，食人。 ⟨異文 在狌狌／在狌狌知人名；貙，龍首／龍首⟩

<a id="SHJ-10-1-014"></a>**`SHJ-10-1-014`** 有木，其狀如牛，引之有皮，若纓、黃蛇。其葉如羅，其實如欒，其木如蓲，其名曰建木。在窫窳西弱水上。 ⟨異文 如／若⟩

<a id="SHJ-10-1-015"></a>**`SHJ-10-1-015`** 氐人國在建木西，其為人人面而魚身，無足。

<a id="SHJ-10-1-016"></a>**`SHJ-10-1-016`** 巴蛇食象，三歲而出其骨，君子服之，無心腹之疾。其為蛇青黃赤黑。一曰黑蛇青首，在犀牛西。

<a id="SHJ-10-1-017"></a>**`SHJ-10-1-017`** 旄馬，其狀如馬，四節有毛。在巴蛇西北，高山南。

<a id="SHJ-10-1-018"></a>**`SHJ-10-1-018`** 匈奴、開題之國、列人之國並在西北。 ⟨異文 匈奴、開題之國、列人之國並在西北。／或無此句；吳承志山海經地理今釋卷六云：「此經當與下篇首條並在海內北經『有人曰大行伯』之上……」⟩
