## 海外北經

<a id="SHJ-08-1-001"></a>**`SHJ-08-1-001`** 海外自東北陬至西北陬者。

<a id="SHJ-08-1-002"></a>**`SHJ-08-1-002`** 無啓之國在長股東，為人無啓。 ⟨異文 啓／𦜹；啓／𦜹⟩

<a id="SHJ-08-1-003"></a>**`SHJ-08-1-003`** 鍾山之神名曰燭陰，視為晝，瞑為夜，吹為冬，呼為夏，不飲，不食，不息，息為風，身長千里。在無啓之東。其為物，人面，蛇身，赤色，居鍾山下。 ⟨異文 啓／𦜹⟩

<a id="SHJ-08-1-004"></a>**`SHJ-08-1-004`** 一目國在其東，一目中其面而居。 ⟨異文 一目中其面而居／一目中其面而居。一曰有手足⟩

<a id="SHJ-08-1-005"></a>**`SHJ-08-1-005`** 柔利國在一目東，為人一手一足，反厀，曲足居上。一云留利之國，人足反折。

<a id="SHJ-08-1-006"></a>**`SHJ-08-1-006`** 共工之臣曰相柳氏，九首，以食于九山。相柳之所抵，厥為澤谿。禹殺相柳，其血腥，不可以樹五穀種。禹厥之，三仞三沮，乃以為眾帝之臺。在昆侖之北，柔利之東。相柳者，九首人面，蛇身而青。不敢北射，畏共工之臺。臺在其東，臺四方，隅有一蛇，虎色，首衝南方。

<a id="SHJ-08-1-007"></a>**`SHJ-08-1-007`** 深目國在其東，為人深目，舉一手，一曰在共工臺東。 ⟨異文 為人深目，舉一手，一曰在共工臺東／為人舉一手一目，在共工臺東⟩

<a id="SHJ-08-1-008"></a>**`SHJ-08-1-008`** 無腸之國在深目東，其為人長而無腸。

<a id="SHJ-08-1-009"></a>**`SHJ-08-1-009`** 聶耳之國在無腸國東，使兩文虎，為人兩手聶其耳。縣居海水中，及水所出入奇物。兩虎在其東。

<a id="SHJ-08-1-010"></a>**`SHJ-08-1-010`** 夸父與日逐走，入日。渴，欲得飲，飲於河、渭，河、渭不足，北飲大澤。未至，道渴而死。棄其杖，化為鄧林。

<a id="SHJ-08-1-011"></a>**`SHJ-08-1-011`** 夸父國在聶耳東，其為人大，右手操青蛇，左手操黃蛇。鄧林在其東，二樹木。一曰博父。 ⟨異文 夸／博⟩

<a id="SHJ-08-1-012"></a>**`SHJ-08-1-012`** 禹所積石之山在其東，河水所入。

<a id="SHJ-08-1-013"></a>**`SHJ-08-1-013`** 拘癭之國在其東，一手把癭。一曰利癭之國。 ⟨異文 癭／纓；癭／纓；癭／纓⟩

<a id="SHJ-08-1-014"></a>**`SHJ-08-1-014`** 尋木長千里，在拘癭南，生河上西北。 ⟨異文 癭／纓⟩

<a id="SHJ-08-1-015"></a>**`SHJ-08-1-015`** 跂踵國在拘癭南，其為人兩足皆支。一曰反踵。 ⟨異文 癭／纓；南／東；其為人兩足皆支／其為人大，兩足亦大；反／大⟩

<a id="SHJ-08-1-016"></a>**`SHJ-08-1-016`** 歐絲之野在反踵東，一女子跪據樹歐絲。 ⟨異文 反／大⟩

<a id="SHJ-08-1-017"></a>**`SHJ-08-1-017`** 三桑無枝，在歐絲東，其木長百仞，無枝。

<a id="SHJ-08-1-018"></a>**`SHJ-08-1-018`** 范林方三百里，在三桑東，洲環其下。

<a id="SHJ-08-1-019"></a>**`SHJ-08-1-019`** 務隅之山，帝顓頊葬于陽。九嬪葬于陰。一曰爰有熊、羆、文虎、離朱、𩿨久、視肉。

<a id="SHJ-08-1-020"></a>**`SHJ-08-1-020`** 平丘在三桑東，爰有遺玉、青鳥、視肉、楊柳、甘柤、甘華，百果所生。有兩山夾上谷，二大丘居中，名曰平丘。

<a id="SHJ-08-1-021"></a>**`SHJ-08-1-021`** 北海內有獸，其狀如馬，名曰騊駼。有獸焉，其名曰駮，狀如白馬，鋸牙，食虎豹。有素獸焉，狀如馬，名曰蛩蛩。有青獸焉，狀如虎，名曰羅羅。

<a id="SHJ-08-1-022"></a>**`SHJ-08-1-022`** 北方禺彊，人面鳥身，珥兩青蛇。踐兩青蛇。
