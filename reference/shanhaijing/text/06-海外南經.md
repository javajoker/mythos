## 海外南經

<a id="SHJ-06-1-001"></a>**`SHJ-06-1-001`** 地之所載，六合之閒，四海之內，照之以日月，經之以星辰，紀之以四時，要之以太歲，神靈所生，其物異形，或夭或壽，唯聖人能通其道。 ⟨異文 閒／間⟩

<a id="SHJ-06-1-002"></a>**`SHJ-06-1-002`** 海外自西南陬至東南陬者。

<a id="SHJ-06-1-003"></a>**`SHJ-06-1-003`** 結匈國在其西南，其為人結匈。

<a id="SHJ-06-1-004"></a>**`SHJ-06-1-004`** 南山在其東南。自此山來，蟲為蛇，蛇號為魚。一曰南山在結匈東南。比翼鳥在其東，其為鳥青、赤，兩鳥比翼。一曰在南山東。

<a id="SHJ-06-1-005"></a>**`SHJ-06-1-005`** 羽民國在其東南，其為人長頭，身生羽。一曰在比翼鳥東南，其為人長頰。

<a id="SHJ-06-1-006"></a>**`SHJ-06-1-006`** 有神人二八，連臂，為帝司夜于此野。在羽民東。其為小人頰赤肩，盡十六人。

<a id="SHJ-06-1-007"></a>**`SHJ-06-1-007`** 畢方鳥在其東，青水西，其為鳥一腳。一曰在二八神東。 ⟨異文 一腳／人面一腳⟩

<a id="SHJ-06-1-008"></a>**`SHJ-06-1-008`** 讙頭國在其南，其為人人面有翼，鳥喙，方捕魚。一曰在畢方東。或曰讙朱國。

<a id="SHJ-06-1-009"></a>**`SHJ-06-1-009`** 厭火國在其南，獸身黑色。生火出其口中。一曰在讙朱東。 ⟨異文 其南／其國南⟩

<a id="SHJ-06-1-010"></a>**`SHJ-06-1-010`** 三株樹在厭火北，生赤水上，其為樹如柏，葉皆為珠。一曰其為樹若彗。

<a id="SHJ-06-1-011"></a>**`SHJ-06-1-011`** 三苗國在赤水東，其為人相隨。一曰三毛國。

<a id="SHJ-06-1-012"></a>**`SHJ-06-1-012`** 臷國在其東，其為人黃，能操弓射蛇。一曰臷國在三毛東。

<a id="SHJ-06-1-013"></a>**`SHJ-06-1-013`** 貫匈國在其東，其為人匈有竅。一曰在臷國東。

<a id="SHJ-06-1-014"></a>**`SHJ-06-1-014`** 交脛國在其東，其為人交脛。一曰在穿匈東。

<a id="SHJ-06-1-015"></a>**`SHJ-06-1-015`** 不死民在其東，其為人黑色，壽，不死。一曰在穿匈國東。

<a id="SHJ-06-1-016"></a>**`SHJ-06-1-016`** 反舌國在其東，其為人反舌。一日支舌國在不死民東。 ⟨異文 反舌國在其東，其為人反舌。一日支舌國在不死民東／岐舌國在其東，一曰在不死民東⟩

<a id="SHJ-06-1-017"></a>**`SHJ-06-1-017`** 昆侖虛在其東，虛四方。一曰在反舌東，為虛四方。 ⟨異文 反／岐⟩

<a id="SHJ-06-1-018"></a>**`SHJ-06-1-018`** 羿與鑿齒戰于壽華之野，羿射殺之。在昆侖虛東。羿持弓矢，鑿齒持盾。一曰持戈。 ⟨異文 持戈／戈⟩

<a id="SHJ-06-1-019"></a>**`SHJ-06-1-019`** 三首國在其東，其為人一身三首。一曰在鑿齒東。

<a id="SHJ-06-1-020"></a>**`SHJ-06-1-020`** 周饒國在其東，其為人短小，冠帶。一曰焦僥國在三首東。

<a id="SHJ-06-1-021"></a>**`SHJ-06-1-021`** 長臂國在其東，捕魚水中，兩手各操一魚。一曰在焦僥東，捕魚海中。

<a id="SHJ-06-1-022"></a>**`SHJ-06-1-022`** 狄山，帝堯葬于陽，帝嚳葬于陰。爰有熊、羆、文虎、蜼、豹、離朱、視肉。吁咽、文王皆葬其所。一曰湯山。一曰爰有熊、羆、文虎、蜼、豹、離朱、𩿨久、視肉、虖交。有范林方三百里。

<a id="SHJ-06-1-023"></a>**`SHJ-06-1-023`** 南方祝融，獸身人面，乘兩龍。
