## 海外西經

<a id="SHJ-07-1-001"></a>**`SHJ-07-1-001`** 海外自西南陬至西北陬者。

<a id="SHJ-07-1-002"></a>**`SHJ-07-1-002`** 滅蒙鳥在結匈國北，為鳥青，赤尾。

<a id="SHJ-07-1-003"></a>**`SHJ-07-1-003`** 大運山高三百仞，在滅蒙鳥北。

<a id="SHJ-07-1-004"></a>**`SHJ-07-1-004`** 大樂之野，夏后啟于此儛九代；乘兩龍，雲蓋三層。左手操翳，右手操環，佩玉璜。在大運山北。一曰大遺之野。

<a id="SHJ-07-1-005"></a>**`SHJ-07-1-005`** 三身國在夏后啟北，一首而三身。

<a id="SHJ-07-1-006"></a>**`SHJ-07-1-006`** 一臂國在其北，一臂、一目、一鼻孔。有黃馬虎文，一目而一手。

<a id="SHJ-07-1-007"></a>**`SHJ-07-1-007`** 奇肱之國在其北，其人一臂三目，有陰有陽，乘文馬。有鳥焉，兩頭，赤黃色，在其旁。

<a id="SHJ-07-1-008"></a>**`SHJ-07-1-008`** 刑天與帝爭神，帝斷其首，葬之常羊之山，乃以乳為目，以臍為口，操干戚以舞。 ⟨異文 刑／形；爭神／至此爭神⟩

<a id="SHJ-07-1-009"></a>**`SHJ-07-1-009`** 女祭、女戚在其北，居兩水閒，戚操魚觛，祭操俎。 ⟨異文 閒／間⟩

<a id="SHJ-07-1-010"></a>**`SHJ-07-1-010`** 䳐鳥、𪆻鳥，其色青黃，所經國亡。在女祭北。䳐鳥人面，居山上。一曰維鳥，青鳥、黃鳥所集。

<a id="SHJ-07-1-011"></a>**`SHJ-07-1-011`** 丈夫國在維鳥北，其為人衣冠帶劍。

<a id="SHJ-07-1-012"></a>**`SHJ-07-1-012`** 女丑之屍，生而十日炙殺之。在丈夫北。以右手鄣其面。十日居上，女丑居山之上。

<a id="SHJ-07-1-013"></a>**`SHJ-07-1-013`** 巫咸國在女丑北，右手操青蛇，左手操赤蛇。在登葆山，群巫所從上下也。

<a id="SHJ-07-1-014"></a>**`SHJ-07-1-014`** 并封在巫咸東，其狀如彘，前後皆有首，黑。

<a id="SHJ-07-1-015"></a>**`SHJ-07-1-015`** 女子國在巫咸北，兩女子居，水周之。一曰居一門中。

<a id="SHJ-07-1-016"></a>**`SHJ-07-1-016`** 軒轅之國在之際，其不壽者八百歲。在女子國北。人面蛇身，尾交首上。 ⟨異文 在／在此⟩

<a id="SHJ-07-1-017"></a>**`SHJ-07-1-017`** 窮山在其北，不敢西射，畏軒轅之丘。在軒轅國北。其丘方，四蛇相繞。

<a id="SHJ-07-1-018"></a>**`SHJ-07-1-018`** 諸夭之野，鸞鳥自歌，鳳鳥自舞；鳳皇卵，民食之；甘露，民飲之，所欲自從也。百獸相與群居。在四蛇北。其人兩手操卵食之，兩鳥居前導之。 ⟨異文 諸夭／此諸夭⟩

<a id="SHJ-07-1-019"></a>**`SHJ-07-1-019`** 龍魚陵居在其北，狀如狸。一曰鰕。即有神聖乘此以行九野。一曰鼈魚在夭野北，其為魚也如鯉。

<a id="SHJ-07-1-020"></a>**`SHJ-07-1-020`** 白民之國在龍魚北，白身披髮。有乘黃，其狀如狐，其背上有角，乘之壽二千歲。

<a id="SHJ-07-1-021"></a>**`SHJ-07-1-021`** 肅慎之國在白民北，有樹名曰雒棠，聖人代立，于此取衣。 ⟨異文 雒棠／雄常；聖人代立，于此取衣／先入伐帝，于此取之⟩

<a id="SHJ-07-1-022"></a>**`SHJ-07-1-022`** 長股之國在雒棠北，被髮。一曰長腳。 ⟨異文 雒棠／雄常⟩

<a id="SHJ-07-1-023"></a>**`SHJ-07-1-023`** 西方蓐收，左耳有蛇，乘兩龍。
