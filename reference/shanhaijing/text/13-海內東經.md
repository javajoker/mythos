## 海內東經

<a id="SHJ-13-1-001"></a>**`SHJ-13-1-001`** 海內東北陬以南者。

<a id="SHJ-13-1-002"></a>**`SHJ-13-1-002`** 鉅燕在東北陬。

<a id="SHJ-13-1-003"></a>**`SHJ-13-1-003`** 蓋國在鉅燕南，倭北。倭屬燕。　　朝鮮在列陽東，海北山南。列陽屬燕。 ⟨異文 蓋國在鉅燕南，倭北。倭屬燕。／國在流沙中者埻端、璽㬇，在昆侖虛東南。一曰海內之郡，不為郡縣，在流沙中。；朝鮮在列陽東，海北山南。列陽屬燕。／國在流沙外者，大夏、豎沙、居繇、月支之國。⟩

<a id="SHJ-13-1-004"></a>**`SHJ-13-1-004`** 列姑射在海河州中。 ⟨異文 列姑射在海河州中。／西胡白玉山在大夏東，蒼梧在白玉山西南，皆在流沙西，昆侖虛東南。昆侖山在西胡西，皆在西北。⟩

<a id="SHJ-13-1-005"></a>**`SHJ-13-1-005`** 雷澤中有雷神，龍身而人頭，鼓其腹。在吳西。

<a id="SHJ-13-1-006"></a>**`SHJ-13-1-006`** 都州在海中。一曰郁州。

<a id="SHJ-13-1-007"></a>**`SHJ-13-1-007`** 琅邪臺在渤海閒，琅邪之東。其北有山。一曰在海閒。 ⟨異文 閒／間；閒／間⟩

<a id="SHJ-13-1-008"></a>**`SHJ-13-1-008`** 韓鴈在海中，都州南。

<a id="SHJ-13-1-009"></a>**`SHJ-13-1-009`** 始鳩在海中，轅厲南。

<a id="SHJ-13-1-010"></a>**`SHJ-13-1-010`** 會稽山在大楚南。 ⟨異文 楚／越⟩

<a id="SHJ-13-1-011"></a>**`SHJ-13-1-011`** 岷三江：首江出汶山，北江曼山，南江出高山。高山在都，西入海，在長州南。

<a id="SHJ-13-1-012"></a>**`SHJ-13-1-012`** 淅江出三天子，都在東，在閩西北，入海，餘暨南。

<a id="SHJ-13-1-013"></a>**`SHJ-13-1-013`** 廬江出三天子，都入江，彭澤西，一曰天子鄣。

<a id="SHJ-13-1-014"></a>**`SHJ-13-1-014`** 淮水出餘山，餘山在朝陽東，義鄉西，入海，淮浦北。

<a id="SHJ-13-1-015"></a>**`SHJ-13-1-015`** 湘水出舜葬東南陬，西環之，入洞庭下，一曰東南西澤。

<a id="SHJ-13-1-016"></a>**`SHJ-13-1-016`** 漢水出鮒魚之山，帝顓頊葬于陽，九嬪葬于陰，四蛇衛之。

<a id="SHJ-13-1-017"></a>**`SHJ-13-1-017`** 濛水出漢陽，西入江，聶陽西。

<a id="SHJ-13-1-018"></a>**`SHJ-13-1-018`** 溫水出崆峒山，在臨汾，南入灑，華陽北。

<a id="SHJ-13-1-019"></a>**`SHJ-13-1-019`** 潁水出少室，少室山在雍氏，南入淮，西鄢北。一曰緱氏。

<a id="SHJ-13-1-020"></a>**`SHJ-13-1-020`** 汝水出天息山，在梁勉鄉，西南入淮，極西北。一曰淮在期思北。

<a id="SHJ-13-1-021"></a>**`SHJ-13-1-021`** 涇水出長城北山，山在郁致，長垣北，北入謂戲北。

<a id="SHJ-13-1-022"></a>**`SHJ-13-1-022`** 渭水出烏鼠同穴山，東注河，入華陰北。

<a id="SHJ-13-1-023"></a>**`SHJ-13-1-023`** 白水出蜀，而東南注江。入江州城下。

<a id="SHJ-13-1-024"></a>**`SHJ-13-1-024`** 沅水山出象郡，鐔城西。入東注江，入下雋西，合洞庭中。

<a id="SHJ-13-1-025"></a>**`SHJ-13-1-025`** 贑水出聶都東山，東北注江，入彭澤。

<a id="SHJ-13-1-026"></a>**`SHJ-13-1-026`** 西泗水出吳東北而南、西南，過湖陵西而東南，注東海，入淮陰北。

<a id="SHJ-13-1-027"></a>**`SHJ-13-1-027`** 鬱水出象郡而西南，注南海，入須陵東南。

<a id="SHJ-13-1-028"></a>**`SHJ-13-1-028`** 肆水出臨晉，西南而東南注海，入番隅西。

<a id="SHJ-13-1-029"></a>**`SHJ-13-1-029`** 潢水出桂陽西北山，東南注肆水，入敦浦西。

<a id="SHJ-13-1-030"></a>**`SHJ-13-1-030`** 洛水出洛西山，東北注河，入成臯之西。

<a id="SHJ-13-1-031"></a>**`SHJ-13-1-031`** 汾水出上窳北，而西南注河，入皮氏南。

<a id="SHJ-13-1-032"></a>**`SHJ-13-1-032`** 沁水出井陘山東，東南注河，入懷東南。

<a id="SHJ-13-1-033"></a>**`SHJ-13-1-033`** 濟水出共山南東丘，絕鉅鹿澤，注渤海，入齊琅槐東北。

<a id="SHJ-13-1-034"></a>**`SHJ-13-1-034`** 潦水出衛臯東，東南注渤海，入遼陽。

<a id="SHJ-13-1-035"></a>**`SHJ-13-1-035`** 虖沲水出晉陽城南，而西至陽曲北，而東注渤海，入越章武北。

<a id="SHJ-13-1-036"></a>**`SHJ-13-1-036`** 漳水出山陽東，東注渤海，入章武南。

<a id="SHJ-13-1-037"></a>**`SHJ-13-1-037`** 姑射國在海中，屬列姑射，西南，山環之。

<a id="SHJ-13-1-038"></a>**`SHJ-13-1-038`** 大蟹在海中。

<a id="SHJ-13-1-039"></a>**`SHJ-13-1-039`** 陵魚人面，手足，魚身，在海中。

<a id="SHJ-13-1-040"></a>**`SHJ-13-1-040`** 大鯾居海中。

<a id="SHJ-13-1-041"></a>**`SHJ-13-1-041`** 明組邑居海中。

<a id="SHJ-13-1-042"></a>**`SHJ-13-1-042`** 蓬萊山在海中。

<a id="SHJ-13-1-043"></a>**`SHJ-13-1-043`** 大人之市在海中。

<a id="SHJ-13-1-044"></a>**`SHJ-13-1-044`** 建平元年四月丙戌，待詔太常屬臣望校治，侍中光祿勳臣龔、侍中奉車都尉光祿大夫臣秀領主省。
