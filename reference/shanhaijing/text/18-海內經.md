## 海內經

<a id="SHJ-18-1-001"></a>**`SHJ-18-1-001`** 東海之内，北海之隅，有國名曰朝鮮；天毒，其人水居，偎人愛人。 ⟨異文 海／經；人／之⟩

<a id="SHJ-18-1-002"></a>**`SHJ-18-1-002`** 西海之内，流沙之中，有國名曰壑市。

<a id="SHJ-18-1-003"></a>**`SHJ-18-1-003`** 西海之内，流沙之西，有國名曰氾葉。 ⟨異文 氾／沮⟩

<a id="SHJ-18-1-004"></a>**`SHJ-18-1-004`** 流沙之西，有鳥山者，三水出焉。爰有黄金、璿瑰、丹貨、銀鐵，皆流于此中。又有淮山，好水出焉。

<a id="SHJ-18-1-005"></a>**`SHJ-18-1-005`** 流沙之東，黑水之西，有朝雲之國、司彘之國。黄帝妻嫘祖，生昌意。昌意降處若水，生韓流。韓流擢首、謹耳、人面、豕喙、麟身、渠股、豚止，取淖子曰阿女，生帝顓頊。

<a id="SHJ-18-1-006"></a>**`SHJ-18-1-006`** 流沙之東，黑水之閒，有山名不死之山。 ⟨異文 閒／間⟩

<a id="SHJ-18-1-007"></a>**`SHJ-18-1-007`** 華山青水之東，有山名曰肇山。有人名曰柏子高，柏子高上下於此，至于天。 ⟨異文 柏子高／柏高；柏子高／柏高⟩

<a id="SHJ-18-1-008"></a>**`SHJ-18-1-008`** 西南黑水之閒，有都廣之野，后稷葬焉。其城方三百里，蓋天地之中，素女所出也。爰有膏菽、膏稻、膏黍、膏稷，百榖自生，冬夏播琴。鸞鳥自歌，鳯鳥自儛，靈壽實華，草木所聚。爰有百獸，相羣爰處。此草也，冬夏不死。 ⟨異文 閒／間；其城方三百里，蓋天地之中，素女所出也。／或無此句⟩

<a id="SHJ-18-1-009"></a>**`SHJ-18-1-009`** 南海之内，黑水青水之閒，有水名曰若木，若水出焉。 ⟨異文 閒／間⟩

<a id="SHJ-18-1-010"></a>**`SHJ-18-1-010`** 有禺中之國。有列襄之國。有靈山，有赤蛇在木上，名曰蝡蛇，木食。

<a id="SHJ-18-1-011"></a>**`SHJ-18-1-011`** 有鹽長之國。有人焉鳥首，名曰鳥民。 ⟨異文 鳥民／鳥氏⟩

<a id="SHJ-18-1-012"></a>**`SHJ-18-1-012`** 有九丘，以水絡之，名曰陶唐之丘、叔得之丘、孟盈之丘、昆吾之丘、黑白之丘、赤望之丘、參衛之丘、武夫之丘、神民之丘。有木，青葉紫莖，玄華黄實，名曰建木，百仭無枝，上有九欘，下有九枸，其實如麻，其葉如芒。大皥爰過，黄帝所為。 ⟨異文 叔得之丘／有叔得之丘；上有九欘／有九欘⟩

<a id="SHJ-18-1-013"></a>**`SHJ-18-1-013`** 有窫窳，龍首，是食人。有青獸，人面，名曰猩猩。

<a id="SHJ-18-1-014"></a>**`SHJ-18-1-014`** 西南有巴國。大皥生咸鳥，咸鳥生乘釐，乘釐生後照，後照是始為巴人。

<a id="SHJ-18-1-015"></a>**`SHJ-18-1-015`** 有國名曰流黄辛氏，其域中方三百里，其出是塵。有巴遂山，澠水出焉。 ⟨異文 塵／塵土⟩

<a id="SHJ-18-1-016"></a>**`SHJ-18-1-016`** 又有朱卷之國。有黑蛇，青首，食象。

<a id="SHJ-18-1-017"></a>**`SHJ-18-1-017`** 南方有贑巨人，人面長脣，黑身有毛，反踵，見人則笑，唇蔽其目，因可逃也。 ⟨異文 脣／臂；見人則笑／見人笑亦笑；目／面；可／即⟩

<a id="SHJ-18-1-018"></a>**`SHJ-18-1-018`** 又有黑人，虎首鳥足，兩手持蛇，方啗之。

<a id="SHJ-18-1-019"></a>**`SHJ-18-1-019`** 有羸民，鳥足，有封豕。

<a id="SHJ-18-1-020"></a>**`SHJ-18-1-020`** 有人曰苖民。有神焉，人首蛇身，長如轅，左右有首，衣紫衣，冠旃冠，名曰延維，人主得而饗食之，伯天下。

<a id="SHJ-18-1-021"></a>**`SHJ-18-1-021`** 有鸞鳥自歌，鳯鳥自儛。鳯鳥首文曰德，翼文曰順，膺文曰仁，背文曰義，見則天下和。 ⟨異文 儛／舞⟩

<a id="SHJ-18-1-022"></a>**`SHJ-18-1-022`** 又有青獸如莵，名曰𡹤狗。有翠鳥。有孔鳥。

<a id="SHJ-18-1-023"></a>**`SHJ-18-1-023`** 南海之内有衡山，有菌山，有桂山。有山名三天子之都。

<a id="SHJ-18-1-024"></a>**`SHJ-18-1-024`** 南方蒼梧之丘，蒼梧之淵，其中有九嶷山，舜之所葬，在長沙零陵界中。

<a id="SHJ-18-1-025"></a>**`SHJ-18-1-025`** 北海之内，有蛇山者，蛇水出焉，東入于海。有五彩之鳥，飛蔽一鄉，名曰翳鳥。又有不鉅之山，巧倕葬其西。 ⟨異文 鉅／距⟩

<a id="SHJ-18-1-026"></a>**`SHJ-18-1-026`** 北海之内，有反縛盗械，帶戈常倍之佐，名曰相顧之尸。

<a id="SHJ-18-1-027"></a>**`SHJ-18-1-027`** 伯夷父生西岳，西岳生先龍，先龍是始生氐羌，氐羌乞姓。

<a id="SHJ-18-1-028"></a>**`SHJ-18-1-028`** 北海之内，有山，名曰幽都之山，黑水出焉。其上有玄鳥、玄蛇、玄豹、玄虎、玄孤蓬尾。有大玄之山。有玄丘之民。有大幽之國。有赤脛之民。

<a id="SHJ-18-1-029"></a>**`SHJ-18-1-029`** 有釘靈之國，其民從䣛已下有毛，馬蹏善走。 ⟨異文 䣛／膝⟩

<a id="SHJ-18-1-030"></a>**`SHJ-18-1-030`** 炎帝之孫伯陵，伯陵同吳權之妻阿女緣婦，緣婦孕三年，是生鼓、延、殳。殳始為侯，鼓、延是始為鍾，為樂風。 ⟨異文 殳始為侯／始為侯⟩

<a id="SHJ-18-1-031"></a>**`SHJ-18-1-031`** 黄帝生駱明，駱明生白馬，白馬是為鯀。

<a id="SHJ-18-1-032"></a>**`SHJ-18-1-032`** 帝俊生禺號，禺號生淫梁，淫梁生番禺，是始為舟。番禺生奚仲，奚仲生吉光，吉光是始以木為車。

<a id="SHJ-18-1-033"></a>**`SHJ-18-1-033`** 少皥生般，般是始為弓矢。

<a id="SHJ-18-1-034"></a>**`SHJ-18-1-034`** 帝俊賜羿彤弓素矰，以扶下國，羿是始去恤下地之百艱。

<a id="SHJ-18-1-035"></a>**`SHJ-18-1-035`** 帝俊生晏龍，晏龍是為琴瑟。

<a id="SHJ-18-1-036"></a>**`SHJ-18-1-036`** 帝俊有子八人，是始為歌舞。

<a id="SHJ-18-1-037"></a>**`SHJ-18-1-037`** 帝俊生三身，三身生義均，義均是始為巧倕，是始作下民百巧。后稷是播百榖。稷之孫曰叔均，始作牛耕。大比赤隂，是始為國。禹、鯀是始布土，均定九州。 ⟨異文 始作牛耕／是始作牛耕⟩

<a id="SHJ-18-1-038"></a>**`SHJ-18-1-038`** 炎帝之妻，赤水之子聽訞生炎居，炎居生節竝，節竝生戲器，戲器生祝融，祝融降處於江水，生共工。共工生術器，術器首方顚，是復土穰，以處江水。共工生后土，后土生噎鳴，噎鳴生歳十有二。 ⟨異文 竝／並；竝／並⟩

<a id="SHJ-18-1-039"></a>**`SHJ-18-1-039`** 洪水滔天。鯀竊帝之息壤以堙洪水，不待帝命。帝令祝融殺鯀于羽郊。鯀復生禹。帝乃命禹卒布土以定九州。
