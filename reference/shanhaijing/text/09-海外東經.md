## 海外東經

<a id="SHJ-09-1-001"></a>**`SHJ-09-1-001`** 海外自東南陬至東北陬者。

<a id="SHJ-09-1-002"></a>**`SHJ-09-1-002`** 𨲠丘，爰有遺玉、青馬、視肉、楊桃、甘柤。甘華，百果所生。在東海，兩山夾丘，上有樹木。一曰嗟丘，一曰百果所在，在堯葬東。 ⟨異文 桃／柳⟩

<a id="SHJ-09-1-003"></a>**`SHJ-09-1-003`** 大人國在其北，為人大，坐而削船。一曰在镸𨲠丘北。

<a id="SHJ-09-1-004"></a>**`SHJ-09-1-004`** 奢比之尸在其北，獸身、人面、大耳，珥兩青蛇。一曰肝榆之尸，在大人北。

<a id="SHJ-09-1-005"></a>**`SHJ-09-1-005`** 君子國在其北，衣冠帶劍，食獸，使二文虎在旁，其人好讓不爭。有薰華草，朝生夕死。一曰在肝榆之尸北。 ⟨異文 文／大⟩

<a id="SHJ-09-1-006"></a>**`SHJ-09-1-006`** 𧈫𧈫在其北，各有兩首。一曰在君子國北。

<a id="SHJ-09-1-007"></a>**`SHJ-09-1-007`** 朝陽之谷，神曰天吳，是為水伯。在𧈫𧈫北兩水間。其為獸也，八首人面，八足八尾，背青黃。 ⟨異文 背／皆⟩

<a id="SHJ-09-1-008"></a>**`SHJ-09-1-008`** 青丘國在其北，其人食五穀，衣絲帛。其狐四足九尾。一曰在朝陽北。 ⟨異文 青丘國在其北，其人食五穀，衣絲帛。／青丘國在其北，⟩

<a id="SHJ-09-1-009"></a>**`SHJ-09-1-009`** 帝命豎亥步，自東極至于西極，五億十選九千八百步。豎亥右手把筭，左手指青丘北。一曰禹令豎亥。一曰五億十萬九千八百步。 ⟨異文 筭／算⟩

<a id="SHJ-09-1-010"></a>**`SHJ-09-1-010`** 黑齒國在其北，為人黑，食稻啖蛇，一赤一青，在其旁。一曰：在豎亥北，為人黑首，食稻使蛇，其一蛇赤。

<a id="SHJ-09-1-011"></a>**`SHJ-09-1-011`** 下有湯谷。湯谷上有扶桑，十日所浴，在黑齒北。居水中，有大木，九日居下枝，一日居上枝。

<a id="SHJ-09-1-012"></a>**`SHJ-09-1-012`** 雨師妾國在其北，其為人黑，兩手各操一蛇，左耳有青蛇，右耳有赤蛇。一曰在十日北，為人黑身人面，各操一龜。 ⟨異文 雨師妾國／雨師妾⟩

<a id="SHJ-09-1-013"></a>**`SHJ-09-1-013`** 玄股之國在其北，其為人股黑，衣魚食䳼，使兩鳥夾之。一曰在雨師妾國北。 ⟨異文 其為人股黑，衣魚食䳼／其為人衣魚食䳼；雨師妾國／雨師妾⟩

<a id="SHJ-09-1-014"></a>**`SHJ-09-1-014`** 毛民之國在其北，為人身生毛。一曰在玄股北。

<a id="SHJ-09-1-015"></a>**`SHJ-09-1-015`** 勞民國在其北，其為人黑，食果草實。有一鳥兩頭。或曰教民。一曰在毛民北，為人面目手足盡黑。 ⟨異文 其為人黑，食果草實。有一鳥兩頭／其為人黑⟩

<a id="SHJ-09-1-016"></a>**`SHJ-09-1-016`** 東方句芒，鳥身人面，乘兩龍。

<a id="SHJ-09-1-017"></a>**`SHJ-09-1-017`** 建平元年四月丙戌，待詔太常屬臣望校治，侍中光祿勳臣龔、侍中奉車都尉光祿大夫臣秀領主省。
