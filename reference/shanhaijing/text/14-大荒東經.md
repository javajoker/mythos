## 大荒東經

<a id="SHJ-14-1-001"></a>**`SHJ-14-1-001`** 東海之外大壑，少昊之國。少昊孺帝顓頊于此，棄其琴瑟。有甘山者，甘水出焉，生甘淵。

<a id="SHJ-14-1-002"></a>**`SHJ-14-1-002`** 東海之外，甘水之閒，有羲和之國。有女子名曰羲和，方浴日于甘淵。羲和者，帝俊之妻，是生十日。

<a id="SHJ-14-1-003"></a>**`SHJ-14-1-003`** 大荒東南隅有山，名皮母地丘。

<a id="SHJ-14-1-004"></a>**`SHJ-14-1-004`** 東海之外，大荒之中，有山名曰大言，日月所出。

<a id="SHJ-14-1-005"></a>**`SHJ-14-1-005`** 有波谷山者，有大人之國。有大人之市，名曰大人之堂。有一大人踆其上，張其兩臂。 ⟨異文 兩臂／兩耳⟩

<a id="SHJ-14-1-006"></a>**`SHJ-14-1-006`** 有小人國，名靖人。

<a id="SHJ-14-1-007"></a>**`SHJ-14-1-007`** 有神，人面獸身，名曰犁𩵀之尸。

<a id="SHJ-14-1-008"></a>**`SHJ-14-1-008`** 有潏山，楊水出焉。

<a id="SHJ-14-1-009"></a>**`SHJ-14-1-009`** 有蒍國，黍食，使四鳥：虎、豹、熊、羆。

<a id="SHJ-14-1-010"></a>**`SHJ-14-1-010`** 大荒之中，有山名曰合虛，日月所出。

<a id="SHJ-14-1-011"></a>**`SHJ-14-1-011`** 有中容之國。帝俊生中容，中容人食獸、木實，使四鳥：豹、虎、熊、羆。

<a id="SHJ-14-1-012"></a>**`SHJ-14-1-012`** 有東口之山。有君子之國，其人衣冠帶劍。

<a id="SHJ-14-1-013"></a>**`SHJ-14-1-013`** 有司幽之國。帝俊生晏龍，晏龍生司幽，司幽生思士，不妻；思女，不夫。食黍，食獸，是使四鳥。

<a id="SHJ-14-1-014"></a>**`SHJ-14-1-014`** 有大阿之山者。

<a id="SHJ-14-1-015"></a>**`SHJ-14-1-015`** 大荒中有山名曰明星，日月所出。

<a id="SHJ-14-1-016"></a>**`SHJ-14-1-016`** 有白民之國。帝俊生帝鴻，帝鴻生白民，白民銷姓，黍食，使四鳥：虎、豹、熊、羆。

<a id="SHJ-14-1-017"></a>**`SHJ-14-1-017`** 有青丘之國，有狐，九尾。

<a id="SHJ-14-1-018"></a>**`SHJ-14-1-018`** 有柔僕民，是維嬴土之國。

<a id="SHJ-14-1-019"></a>**`SHJ-14-1-019`** 有黑齒之國。帝俊生黑齒，姜姓，黍食，使四鳥。

<a id="SHJ-14-1-020"></a>**`SHJ-14-1-020`** 有夏州之國。有蓋余之國。

<a id="SHJ-14-1-021"></a>**`SHJ-14-1-021`** 有神人，八首人面，虎身十尾，名曰天吳。

<a id="SHJ-14-1-022"></a>**`SHJ-14-1-022`** 大荒之中，有山名曰鞠陵于天、東極、離瞀，日月所出。名曰折丹──東方曰折，來風曰俊──處東極以出入風。

<a id="SHJ-14-1-023"></a>**`SHJ-14-1-023`** 東海之渚中，有神，人面鳥身，珥兩黃蛇，踐兩黃蛇，名曰禺䝞。黃帝生禺禺䝞，禺禺䝞生禺京，禺京處北海，禺䝞處東海，是為海神。 ⟨異文 為／惟⟩

<a id="SHJ-14-1-024"></a>**`SHJ-14-1-024`** 有招搖山，融水出焉。有國曰玄股，黍食，使四鳥。

<a id="SHJ-14-1-025"></a>**`SHJ-14-1-025`** 有困民國，勾姓，黍食。有人曰王亥，兩手操鳥，方食其頭。王亥托于有易、河伯僕牛。有易殺王亥，取僕牛。河伯念有易，有易潛出，為國于獸，方食之，名曰搖民。帝舜生戲，戲生搖民。 ⟨異文 勾姓，黍食／勾姓而食；河伯／河⟩

<a id="SHJ-14-1-026"></a>**`SHJ-14-1-026`** 海內有兩人，名曰女丑。女丑有大蟹。

<a id="SHJ-14-1-027"></a>**`SHJ-14-1-027`** 大荒之中，有山名曰孽搖頵羝，上有扶木，柱三百里，其葉如芥。有谷曰溫源谷。湯谷上有扶木。一日方至，一日方出，皆載于烏。

<a id="SHJ-14-1-028"></a>**`SHJ-14-1-028`** 有神，人面、犬耳、獸身，珥兩青蛇，名曰奢比尸。

<a id="SHJ-14-1-029"></a>**`SHJ-14-1-029`** 有五采之鳥，相鄉棄沙。惟帝俊下友。帝下兩壇，采鳥是司。

<a id="SHJ-14-1-030"></a>**`SHJ-14-1-030`** 大荒之中，有山名猗天蘇門，日月所生。有壎民之國。 ⟨異文 有山名／有山名曰⟩

<a id="SHJ-14-1-031"></a>**`SHJ-14-1-031`** 有綦山。又有搖山。有䰝山，又有門戶山。又有盛山。又有待山。有五采之鳥。

<a id="SHJ-14-1-032"></a>**`SHJ-14-1-032`** 東荒之中，有山名曰壑明俊疾，日月所出。有中容之國。

<a id="SHJ-14-1-033"></a>**`SHJ-14-1-033`** 東北海外，又有三青馬、三騅、甘華。爰有遺玉、三青鳥、三騅、視肉、甘華、甘柤，百穀所在。

<a id="SHJ-14-1-034"></a>**`SHJ-14-1-034`** 有女和月母之國。有人名曰𪂧，北方曰𪂧，來風曰𤟇，是處東北隅以止日月，使無相閒出沒，司其短長。 ⟨異文 來風／來之風；北／極；閒／間⟩

<a id="SHJ-14-1-035"></a>**`SHJ-14-1-035`** 大荒東北隅中，有山名曰凶犁土丘。應龍出南極，殺蚩尤與夸父，不得復上。故下數旱，旱而為應龍之狀，乃得大雨。 ⟨異文 出／處⟩

<a id="SHJ-14-1-036"></a>**`SHJ-14-1-036`** 東海中有流波山，入海七千里。其上有獸，狀如牛，蒼身而無角，一足，出入水則必風雨，其光如日月，其聲如雷，其名曰夔。黃帝得之，以其皮為鼓，橛以雷獸之骨，聲聞五百里，以威天下。
