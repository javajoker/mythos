## 海內北經

<a id="SHJ-12-1-001"></a>**`SHJ-12-1-001`** 海內西北陬以東者。

<a id="SHJ-12-1-002"></a>**`SHJ-12-1-002`** 匈奴、開題之國、列人之國並在西北。貳負之臣曰危，危與貳負殺窫窳，帝乃梏之疏屬之山，桎其右足，反縛兩手，繫之山上木。在開題西北。

<a id="SHJ-12-1-003"></a>**`SHJ-12-1-003`** 有人曰大行伯，把戈。其東有犬封國。貳負之尸在大行伯東。

<a id="SHJ-12-1-004"></a>**`SHJ-12-1-004`** 犬封國曰犬戎國，狀如犬。有一女子，方跪進柸食。有文馬，縞身朱鬛，目若黃金，名曰吉量，乘之壽千歲。

<a id="SHJ-12-1-005"></a>**`SHJ-12-1-005`** 鬼國在貳負之尸北，為物人面而一目。一曰貳負神在其東，為物人面蛇身。蜪犬如犬，青，食人從首始。

<a id="SHJ-12-1-006"></a>**`SHJ-12-1-006`** 窮奇狀如虎，有翼，食人從首始，所食被髮，在蜪犬北。一曰從足。

<a id="SHJ-12-1-007"></a>**`SHJ-12-1-007`** 帝堯臺、帝嚳臺、帝丹朱臺、帝舜臺，各二臺，臺四方，在昆侖東北。

<a id="SHJ-12-1-008"></a>**`SHJ-12-1-008`** 大蠭其狀如螽。朱蛾其狀如蛾。

<a id="SHJ-12-1-009"></a>**`SHJ-12-1-009`** 蟜，其為人虎文，脛有𦜹。在窮奇東。一曰，狀如人。昆侖虛北所有。

<a id="SHJ-12-1-010"></a>**`SHJ-12-1-010`** 闒非，人面而獸身，青色。

<a id="SHJ-12-1-011"></a>**`SHJ-12-1-011`** 據比之尸，其為人折頸被髮，無一手。

<a id="SHJ-12-1-012"></a>**`SHJ-12-1-012`** 環狗，其為人獸首人身。一曰蝟狀如狗，黃色。

<a id="SHJ-12-1-013"></a>**`SHJ-12-1-013`** 𥘯，其為物人身黑首從目。

<a id="SHJ-12-1-014"></a>**`SHJ-12-1-014`** 戎，其為人人首三角。

<a id="SHJ-12-1-015"></a>**`SHJ-12-1-015`** 林氏國有珍獸，大若虎，五采畢具，尾長于身，名曰騶吾，乘之日行千里。

<a id="SHJ-12-1-016"></a>**`SHJ-12-1-016`** 昆侖虛南所，有氾林方三百里。

<a id="SHJ-12-1-017"></a>**`SHJ-12-1-017`** 從極之淵深三百仞，維冰夷恒都焉。冰夷人面，乘兩龍。一曰忠極之淵。

<a id="SHJ-12-1-018"></a>**`SHJ-12-1-018`** 陽汙之山，河出其中；淩門之山，河出其中。

<a id="SHJ-12-1-019"></a>**`SHJ-12-1-019`** 王子夜之尸，兩手、兩股、胷、首、齒，皆斷異處。

<a id="SHJ-12-1-020"></a>**`SHJ-12-1-020`** 大澤方百里，羣鳥所生及所解，在鴈門北。

<a id="SHJ-12-1-021"></a>**`SHJ-12-1-021`** 鴈門山，鴈出其閒。在高柳北。

<a id="SHJ-12-1-022"></a>**`SHJ-12-1-022`** 高柳在代北。

<a id="SHJ-12-1-023"></a>**`SHJ-12-1-023`** 舜妻登比氏生宵明、燭光，處河大澤，二女之靈能照此所方百里。一曰登北氏。

<a id="SHJ-12-1-024"></a>**`SHJ-12-1-024`** 東胡在大澤東。

<a id="SHJ-12-1-025"></a>**`SHJ-12-1-025`** 夷人在東胡東。

<a id="SHJ-12-1-026"></a>**`SHJ-12-1-026`** 貊國在漢水東北。地近于燕，滅之。

<a id="SHJ-12-1-027"></a>**`SHJ-12-1-027`** 孟鳥在貊國東北，其鳥文赤、黃、青，東鄉。
