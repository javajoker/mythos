## 大荒西經

<a id="SHJ-16-1-001"></a>**`SHJ-16-1-001`** 西北海之外，大荒之隅，有山而不合，名曰不周，有兩黄獸守之。有水曰寒暑之水，水西有濕山，水東有幕山。有禹攻共工國山。 ⟨異文 不周／不周負子⟩

<a id="SHJ-16-1-002"></a>**`SHJ-16-1-002`** 有國名曰淑士，顓頊之子。

<a id="SHJ-16-1-003"></a>**`SHJ-16-1-003`** 有神十人，名曰女媧之腸，化為神，處栗廣之野，横道而處。

<a id="SHJ-16-1-004"></a>**`SHJ-16-1-004`** 有人名曰石夷，來風曰韋，處西北隅以司日月之長短。

<a id="SHJ-16-1-005"></a>**`SHJ-16-1-005`** 有五采之鳥，有冠，名曰狂鳥。 ⟨異文 采／彩；狂／㹥⟩

<a id="SHJ-16-1-006"></a>**`SHJ-16-1-006`** 有大澤之長山，有白民之國。

<a id="SHJ-16-1-007"></a>**`SHJ-16-1-007`** 西北海之外，赤水之東，有長脛之國。

<a id="SHJ-16-1-008"></a>**`SHJ-16-1-008`** 有西周之國，姬姓，食榖。有人方耕，名曰叔均。帝俊生后稷，稷降以百榖。稷之弟曰台璽，生叔均。叔均是代其父及稷播百榖，始作耕。有赤國妻氏。有雙山。

<a id="SHJ-16-1-009"></a>**`SHJ-16-1-009`** 西海之外，大荒之中，有方山者，上有青樹，名曰柜格之松，日月所出入也。

<a id="SHJ-16-1-010"></a>**`SHJ-16-1-010`** 西北海之外，赤水之西，有天民之國，食榖，使四鳥。 ⟨異文 天／先⟩

<a id="SHJ-16-1-011"></a>**`SHJ-16-1-011`** 有北狄之國。黄帝之孫曰始均，始均生北狄。

<a id="SHJ-16-1-012"></a>**`SHJ-16-1-012`** 有芒山。有桂山。有榣山，其上有人，號曰太子長琴。顓頊生老童，老童生祝融，祝融生太子長琴，是處榣山，始作樂風。

<a id="SHJ-16-1-013"></a>**`SHJ-16-1-013`** 有五采鳥三名：一曰皇鳥，一曰鸞鳥，一曰鳳鳥。 ⟨異文 采／彩⟩

<a id="SHJ-16-1-014"></a>**`SHJ-16-1-014`** 有蟲狀如菟，胷以後者裸不見，青如猨狀。

<a id="SHJ-16-1-015"></a>**`SHJ-16-1-015`** 大荒之中，有山名曰豐沮玉門，日月所入。

<a id="SHJ-16-1-016"></a>**`SHJ-16-1-016`** 有靈山，巫咸、巫即、巫朌、巫彭、巫姑、巫真、巫禮、巫抵、巫謝、巫羅十巫，從此升降，百藥爰在。

<a id="SHJ-16-1-017"></a>**`SHJ-16-1-017`** 西有王母之山、壑山、海山。有沃民之國，沃民是處。沃之野，鳳鳥之卵是食，甘露是飲。凡其所欲，其味盡存。爰有甘華、甘柤、白栁、視肉、三騅、璇瑰、瑶碧、白木、琅玕、白丹、青丹，多銀鐵。鸞鳥自歌，鳳鳥自舞，爰有百獸，相群是處，是謂沃之野。 ⟨異文 沃民／沃⟩

<a id="SHJ-16-1-018"></a>**`SHJ-16-1-018`** 有三青鳥，赤首黒目，一名曰大鵹，一名少鵹，一名曰青鳥。

<a id="SHJ-16-1-019"></a>**`SHJ-16-1-019`** 有軒轅之臺，射者不敢西鄉，畏軒轅之臺。 ⟨異文 鄉／嚮射⟩

<a id="SHJ-16-1-020"></a>**`SHJ-16-1-020`** 大荒之中，有龍山，日月所入。

<a id="SHJ-16-1-021"></a>**`SHJ-16-1-021`** 有三澤水，名曰三淖，昆吾之所食也。

<a id="SHJ-16-1-022"></a>**`SHJ-16-1-022`** 有人衣青，以袂蔽面，名曰女丑之尸。

<a id="SHJ-16-1-023"></a>**`SHJ-16-1-023`** 有女子之國。

<a id="SHJ-16-1-024"></a>**`SHJ-16-1-024`** 有桃山。有䖟山。有桂山。有于土山。

<a id="SHJ-16-1-025"></a>**`SHJ-16-1-025`** 有丈夫之國。

<a id="SHJ-16-1-026"></a>**`SHJ-16-1-026`** 有弇州之山，五采之鳥仰天，名曰鳴鳥。爰有百樂歌儛之風。 ⟨異文 采／彩⟩

<a id="SHJ-16-1-027"></a>**`SHJ-16-1-027`** 有軒轅之國。江山之南棲為吉。不壽者乃八百歲。

<a id="SHJ-16-1-028"></a>**`SHJ-16-1-028`** 西海陼中，有神，人面鳥身，珥兩青蛇，踐兩赤蛇，名曰弇茲。

<a id="SHJ-16-1-029"></a>**`SHJ-16-1-029`** 大荒之中，有山名曰日月山，天樞也。吴姖天門，日月所入。有神，人面無臂，兩足反屬于頭上，名曰嘘。顓頊生老童，老童生重及黎，帝令重獻上天，令黎印下地。下地是生噎，處于西極，以行日月星辰之行次。 ⟨異文 印／卭⟩

<a id="SHJ-16-1-030"></a>**`SHJ-16-1-030`** 有人反臂，名曰天虞。

<a id="SHJ-16-1-031"></a>**`SHJ-16-1-031`** 有女子方浴月。帝俊妻常羲，生月十二，此始浴之。 ⟨異文 十二／十有二⟩

<a id="SHJ-16-1-032"></a>**`SHJ-16-1-032`** 有玄丹之山。有五色之鳥，人面有髮。爰有青鴍、黄鷔、青鳥、黄鳥，其所集者其國亡。

<a id="SHJ-16-1-033"></a>**`SHJ-16-1-033`** 有池，名孟翼之攻顓頊之池。

<a id="SHJ-16-1-034"></a>**`SHJ-16-1-034`** 大荒之中，有山，名曰鏖鏊鉅，日月所入者。

<a id="SHJ-16-1-035"></a>**`SHJ-16-1-035`** 有獸，左右有首，名曰屏蓬。

<a id="SHJ-16-1-036"></a>**`SHJ-16-1-036`** 有巫山者。有壑山者。有金門之山，有人名曰黄姖之尸。有比翼之鳥，有白鳥，青翼，黄尾，玄喙。有赤犬，名曰天犬，其所下者有兵。

<a id="SHJ-16-1-037"></a>**`SHJ-16-1-037`** 西海之南，流沙之濱，赤水之後，黒水之前，有大山，名曰崑崙之丘。有神，人面虎身，有文有尾，皆白，處之。其下有弱水之淵環之，其外有炎火之山，投物輒然。有人，戴勝，虎齒，有豹尾，穴處，名曰西王母。此山萬物盡有。

<a id="SHJ-16-1-038"></a>**`SHJ-16-1-038`** 大荒之中，有山名曰常陽之山，日月所入。

<a id="SHJ-16-1-039"></a>**`SHJ-16-1-039`** 有寒荒之國。有二人女祭、女薎。

<a id="SHJ-16-1-040"></a>**`SHJ-16-1-040`** 有壽麻之國。南嶽娶州山女，名曰女虔。女虔生季格，季格生壽麻。壽麻正立無景，疾呼無響。爰有大暑，不可以往。

<a id="SHJ-16-1-041"></a>**`SHJ-16-1-041`** 有人無首，操戈盾立，名曰夏耕之尸。故成湯伐夏桀于章山，克之，斬耕厥前。耕既立，無首，走厥咎，乃降于巫山。

<a id="SHJ-16-1-042"></a>**`SHJ-16-1-042`** 有人名曰吴回，竒左，是無右臂。

<a id="SHJ-16-1-043"></a>**`SHJ-16-1-043`** 有蓋山之國。有樹，赤皮支幹，青葉，名曰朱木。

<a id="SHJ-16-1-044"></a>**`SHJ-16-1-044`** 有一臂民。

<a id="SHJ-16-1-045"></a>**`SHJ-16-1-045`** 大荒之中，有山名曰大荒之山，日月所入。有人焉三面，是顓頊之子，三面一臂，三面之人不死，是謂大荒之野。

<a id="SHJ-16-1-046"></a>**`SHJ-16-1-046`** 西南海之外，赤水之南，流沙之西，有人珥兩青蛇，乗兩龍，名曰夏后開。開上三嬪于天，得九辯與九歌以下。此天穆之野，髙二千仞，開焉得始歌九招。

<a id="SHJ-16-1-047"></a>**`SHJ-16-1-047`** 有氐人之國。炎帝之孫名曰靈恝，靈恝生氐人，是能上下于天。 ⟨異文 氐／互；氐／互⟩

<a id="SHJ-16-1-048"></a>**`SHJ-16-1-048`** 有魚偏枯，名曰魚婦。顓頊死即復蘇。風道北来，天乃大水泉，蛇乃化為魚，是謂魚婦。顓頊死即復蘇。

<a id="SHJ-16-1-049"></a>**`SHJ-16-1-049`** 有青鳥，身黄，赤足，六首，名曰𪇆鳥。

<a id="SHJ-16-1-050"></a>**`SHJ-16-1-050`** 有大巫山。有金之山。西南，大荒之隅，有偏句、常羊之山。 ⟨異文 隅／中隅；句／勾⟩
