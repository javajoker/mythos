## 大荒北經

<a id="SHJ-17-1-001"></a>**`SHJ-17-1-001`** 東北海之外，大荒之中，河水之閒，附禺之山，帝顓頊與九嬪葬焉。爰有𩿨久、文貝、離俞、鸞鳥、鳳鳥、大物、小物。有青鳥、琅鳥、玄鳥、黄鳥、虎、豹、熊、羆、黄蛇、視肉、璿、瑰、瑶、碧，皆出于山。丘方圓三百里，丘南帝俊竹林在焉，大可為舟。竹南有赤澤水，名曰封淵。有三桑無枝。丘西有沈淵，顓頊所浴。 ⟨異文 閒／間；于山／衛于山⟩

<a id="SHJ-17-1-002"></a>**`SHJ-17-1-002`** 有胡不與之國，烈姓，黍食。

<a id="SHJ-17-1-003"></a>**`SHJ-17-1-003`** 大荒之中，有山名曰不咸，有肅慎氏之國。有蜚蛭，四翼。有蟲，獸首蛇身，名曰琴蟲。

<a id="SHJ-17-1-004"></a>**`SHJ-17-1-004`** 有人名曰大人。有大人之國，釐姓，黍食。有大青蛇，黄頭，食麈。

<a id="SHJ-17-1-005"></a>**`SHJ-17-1-005`** 有榆山。有鯀攻程州之山。

<a id="SHJ-17-1-006"></a>**`SHJ-17-1-006`** 大荒之中，有山名曰衡天。有先民之山。有槃木千里。

<a id="SHJ-17-1-007"></a>**`SHJ-17-1-007`** 有叔歜國，顓頊之子，黍食，使四鳥、虎、豹、熊、羆。有黒蟲如熊狀，名曰猎猎。

<a id="SHJ-17-1-008"></a>**`SHJ-17-1-008`** 有北齊之國，姜姓，使虎、豹、熊、羆。

<a id="SHJ-17-1-009"></a>**`SHJ-17-1-009`** 大荒之中，有山名曰先檻大逢之山，河濟所入，海北注焉。其西有山，名曰禹所積石。

<a id="SHJ-17-1-010"></a>**`SHJ-17-1-010`** 有陽山者。有順山者，順水出焉。有始州之國，有丹山。

<a id="SHJ-17-1-011"></a>**`SHJ-17-1-011`** 有大澤方千里，羣鳥所解。

<a id="SHJ-17-1-012"></a>**`SHJ-17-1-012`** 有毛民之國，依姓，食黍，使四鳥。禹生均國，均國生役采，役采生修鞈，修鞈殺綽人。帝念之，潛為之國，是此毛民。

<a id="SHJ-17-1-013"></a>**`SHJ-17-1-013`** 有儋耳之國，任姓，禺號子，食榖。北海之渚中，有神，人面鳥身，珥兩青蛇，踐兩赤蛇，名曰禺彊。

<a id="SHJ-17-1-014"></a>**`SHJ-17-1-014`** 大荒之中，有山名曰北極天櫃，海外北注焉。有神，九首人面鳥身，名曰九鳳。又有神衘蛇操蛇，其狀虎首人身，四蹏長肘，名曰彊良。 ⟨異文 櫃／樻⟩

<a id="SHJ-17-1-015"></a>**`SHJ-17-1-015`** 大荒之中，有山名曰成都載天。有人珥兩黄蛇，把兩黄蛇，名曰夸父。后土生信，信生夸父。夸父不量力，欲追日景，逮之于禺谷。將飲河而不足也，將走大澤，未至，死于此。應龍已殺蚩尤，又殺夸父，乃去南方處之，故南方多雨。

<a id="SHJ-17-1-016"></a>**`SHJ-17-1-016`** 又有無腸之國，是任姓。無繼子，食魚。

<a id="SHJ-17-1-017"></a>**`SHJ-17-1-017`** 共工臣名曰相繇，九首蛇身，自環，食于九土。其所歍所尼，即為源澤，不辛乃苦，百獸莫能處。禹湮洪水，殺相繇，其血腥臭，不可生榖；其地多水，不可居也。禹湮之，三仞三沮，乃以為池，羣帝因是以為臺。在崑崙之北。 ⟨異文 崑崙／昆侖⟩

<a id="SHJ-17-1-018"></a>**`SHJ-17-1-018`** 有岳之山，尋竹生焉。 ⟨異文 尋／㝷⟩

<a id="SHJ-17-1-019"></a>**`SHJ-17-1-019`** 大荒之中，有山名不句，海水北入焉。 ⟨異文 名／名曰；北入／入⟩

<a id="SHJ-17-1-020"></a>**`SHJ-17-1-020`** 有係昆之山者，有共工之臺，射者不敢北鄉。有人衣青衣，名曰黄帝女魃。蚩尤作兵伐黄帝，黄帝乃令應龍攻之冀州之野。應龍畜水。蚩尤請風伯雨師，縱大風雨。黄帝乃下天女曰魃，雨止，遂殺蚩尤。魃不得復上，所居不雨。叔均言之帝，後置之赤水之北。叔均乃為田祖。魃時亡之，所欲逐之者，令曰：「神北行！」先除水道，决通溝瀆。

<a id="SHJ-17-1-021"></a>**`SHJ-17-1-021`** 有人方食魚，名曰深目民之國，昐姓，食魚。

<a id="SHJ-17-1-022"></a>**`SHJ-17-1-022`** 有鍾山者，有女子衣青衣，名曰赤水女子獻。

<a id="SHJ-17-1-023"></a>**`SHJ-17-1-023`** 大荒之中，有山名曰融父山，順水入焉。有人名曰犬戎。黄帝生苗龍，苗龍生融吾，融吾生弄明，弄明生白犬，白犬有牝牡，是為犬戎，肉食。有赤獸，馬狀，無首，名曰戎宣王尸。

<a id="SHJ-17-1-024"></a>**`SHJ-17-1-024`** 有山名曰齊州之山、君山、𩰿山、鮮野山、魚山。

<a id="SHJ-17-1-025"></a>**`SHJ-17-1-025`** 有人一目，當面中生。一曰是威姓，少昊之子，食黍。

<a id="SHJ-17-1-026"></a>**`SHJ-17-1-026`** 有無繼民，無繼民任姓，無骨子，食氣、魚。 ⟨異文 無繼／繼無；無繼／繼無⟩

<a id="SHJ-17-1-027"></a>**`SHJ-17-1-027`** 西北海外，流沙之東，有國曰中䡢，顓頊之子，食黍。

<a id="SHJ-17-1-028"></a>**`SHJ-17-1-028`** 有國名曰賴丘。有犬戎國。有神，人面獸身，名曰犬戎。

<a id="SHJ-17-1-029"></a>**`SHJ-17-1-029`** 西北海外，黒水之北，有人有翼，名曰苗民。顓頊生驩頭，驩頭生苗民，苗民釐姓，食肉。有山名曰章山。

<a id="SHJ-17-1-030"></a>**`SHJ-17-1-030`** 大荒之中，有衡石山、九陰山、灰野之山、泂野之山，上有赤樹，青葉赤華，名曰若木。

<a id="SHJ-17-1-031"></a>**`SHJ-17-1-031`** 有牛黎之國。有人無骨，儋耳之子。

<a id="SHJ-17-1-032"></a>**`SHJ-17-1-032`** 西北海外，赤水之北，有章尾山。有神，人面蛇身而赤，直目正乘，其暝乃晦，其視乃明，不食不寢不息，風雨是謁。是燭九陰，是謂燭龍。 ⟨異文 海外／海之外⟩
