# 語義相關評分 / Semantic correlation matching

## 統一推論順序

**原文證據 → 靜態形狀與物理特徵 → 古代通用詞義 → 同時代候選 → 相同寬容下的吻合與矛盾 → 可信度與未知項**。

靜態比較包括輪廓、相對位置、連接、環繞、包含、分支與分佈。動態出入只保留為原文線索，候選比較可降為無方向連接；現代水流、後世地名、傳播鏈缺失和現代狹窄分類不得越過此順序提前否決。未知傳播機制標為未知。

## 遮蔽輸入

將實體名稱換成代號，只保留原文描述、名稱特徵、關係摘要和必要的觀察框架。不提供注疏、既有比定或今名。

## 候選與評分

- 每個實體至少三個候選、至少兩個大區；包含真正的對立候選。
- **對立候選硬性要求（紅隊 G-1）**：每條映射至少記一個**已測試**的對立候選，或書面說明何以無對立；`rival_candidates` 補不出者置信度**封頂 low**。零對立候選視為「沒有去找」，不是「沒有競爭者」。
- 每個候選在時代窗口內存在或可見，附年代、狀態和一般性來源。
- 對外觀、顏色、尺度、材質、功能、聲音、生態、方位和年代逐項輸出 `score`、`contradiction`、`evidence`、`attribute`、`reason`。
- 無資料時記 `null`，不以缺失代替矛盾；今名相似與名氣不得分。
- 比例尺只在語料區間內擬合，並與其他模型比較敏感度。

## 整包地理映射

由 LLM 按子經整包為全部 MTN/WAT/LND 節點建立真實世界候選（山/水/地標同包），並交項目發起人確認。共享水體保留為跨山系單一錨定候選；水名為性狀類名（ADJ-005），多地實例合法。每個水體均須比較改道、消亡、萎縮、沼澤化、人工渠道遺址和性狀改變；未知狀態標為未知，不得以現代水文直接否決。

## 遮蔽對照（紅隊 G-2）

除候選生成時的輸入遮蔽外，另設**遮蔽重判**：每鏈抽樣 3–5 段（覆蓋高置信與關鍵錨段），抽去經名與前後鏈，僅給實體清單讓 LLM 獨立定位，再與現有映射比對，記錄一致/分歧率；分歧段降置信並入待裁。此為檢驗先驗污染的強制環節，不是可選抽檢。

### 遮蔽重判操作流程（T-RT05）

1. **生成測試包**：`python3 tools/shj/blind_pack.py --pack <鏈名>:<ENTRY1,ENTRY2,...>`——工具從 working-text 取原文、自動剔除經卷名/鏈首標記/卷末里程總結，輸出含原文＋實體清單、不含站序/錨點/候選/現代地名的測試包。
2. **獨立定位**：把測試包交給未參與該鏈適配的 LLM 實例（或清空上下文的新會話），僅依水系/方位/物產/風物獨立定位，逐條給出區域與經緯帶。
3. **比對記錄**：一致／部分一致（同山系不同段）／分歧（不同山系）三檔計數，寫入該鏈 adaptation 的遮蔽重判節；**一致段置信解封**（medium→原級別），分歧段降一級並入待裁，部分一致記 variant。
4. **鑑別力聲明**：若遮蔽輸入本身支持多解（如格式化流向語言「東流注于海」），須如實記「鑑別力不足」，不得記為一致。

## 網格與里程規則（紅隊 G-3／G-4）

- station-grid 是**否定工具**：輸出為「經度帶 ± 容差」而非點位；候選偏離網格帶太遠則否，但網格點不得直接作候選位。映射以文本實體為準、以網格帶為檢核，衝突記 conflict，不靜默取其一。
- 里程裁決事先聲明：里值檔位（0.35–0.42）、允許區間、方向約定（弦距 vs 路徑距）。單鏈逐腿偏差超 ±50% 必須分段解釋；總帳對沖無效；層累只解釋放大不解釋縮水（縮水記反例）。展示一律三檔帶符號並列。
- 引用 F-0008 等裁決文件時只引其實載數值；虛構出處（如「1.2× 下限」）一經發現即撤回。

## 取樣與紀錄

- 每個判斷至少三個樣本，每次打亂候選順序。
- 記錄 `model`、`prompt_version`、`input_hash`、`sample` 和候選卡版本；輸入不變不重判。
- 抽 10% 做不遮蔽洩漏探測；最佳候選改變或分數差異顯著時標記審查。
- 每批混入 5% 誘餌；高分配上熱門候選時交紅隊。
- 初始屬性寫 `semantic_fit/proposed`，經衝突與紅隊審查後才可接受。

輸出落於 `attributes.jsonl`（由 kg_v1_assemble/kg_readings_build/kg_assoc_ded_build 自適配包組裝）；早期資料模型中的 `candidates.jsonl`/`judgments.jsonl`/`relation-judgments.jsonl` 已廢止，判斷記錄以適配包 mappings 與 findings/ADJ 記錄承載。不由腳本生成理由或結論。
