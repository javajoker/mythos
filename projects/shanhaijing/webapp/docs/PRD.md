# 山海經現實映射 Web App — PRD

> 版本 0.1（2026-10-26）。狀態：待發起人評審。

## 1. 定位與目標

把《山海經》時代假想推理研究成果（18 卷、869 條目、KG 4,334 節點／1,805 邊／9,234 屬性、45 張地圖、111 張實拍配圖）做成一個可探索的交互式 web app：**以太平洋中心世界地圖為主界面，展示山經里程鏈與框架書點位在現實世界的映射，以及地理、人文、動植物、資源特產的時代讀法**。

核心價值：讓讀者一眼看到「某句經文 → 推測的現實位置/對象 → 證據與置信度 → 未決項」，並能理解這是一套競爭假說（proposed_pending_review），不是定論。

## 2. 用戶與場景

| 用戶 | 場景 |
|---|---|
| 發起人/研究者 | 逐條覆核映射與裁決；檢查證據鏈與未決項；導出審核清單 |
| 一般讀者 | 讀山海經的白話解讀；看經文對應的現實山河與動植物照片 |
| 二次開發者 | 取用結構化 KG 數據（JSON）做自己的可視化/研究 |

## 3. 功能需求（P0/P1/P2）

### P0（首版必備）

1. **世界地圖主視圖**（太平洋中心，美洲在中原以東）：26 條山經鏈（按五經色族）＋402 個框架書點位（藍＝復用錨定/金＝區域方向/紅虛框＝待定錨）；縮放/平移；點選鏈或點 → 右側詳情卡。
2. **詳情卡**：原文（繁體照錄）＋白話解讀＋現實候選（含現代山名/水名）＋置信度（很可靠/較可靠/方向性猜測/待考）＋配圖（本地實拍）＋未決項＋裁決標記（ADJ-002…005、借名警示、類名標記）。
3. **卷/子經導覽**：18 卷目錄；每卷一幅補丁圖＋導覽文（取自 draft-v2 卷首）。
4. **實體瀏覽與搜索**：按類型篩選（山體/水體/地標/族群/人物神格/動物/植物/礦物資源）；按名稱搜索（含類名聚合視圖——赤水四實例、流沙五實例等）。
5. **狀態誠實層**：所有頁面展示 proposed_pending_review 標記；未決項與對立候選可見；借名警示（後世同名不反證）有專用視覺樣式。

### P1

6. **時間與置信度過濾**：時代窗口（4000–1000 BCE）說明層＋按置信度篩選地圖點。
7. **關係視圖**：選中實體顯示其 KG 關係（水系流向出/注、方位相鄰、母題關聯、復用鏈）。
8. **裁決記錄頁**：ADJ-002–005 與 F-0001–0012 的可讀列表。
9. **離線可用**：全部數據與圖片本地化，無外部依賴。

### P2

10. 紅隊/覆核工作流（標記已覆核、導出覆核包）。
11. 中英雙語。
12. 3D/地形模式。

## 4. 非功能需求

- 純靜態站（可放任意靜態託管或本地打開）；首屏 ≤ 3 MB（地圖數據精簡、圖片懶加載）。
- 移動端可用（響應式）；桌面端為主。
- 無追蹤、無後端、無賬號。

## 5. 內容邊界（誠實性硬性約束）

- 不得把競爭假說呈現為確定事實；「方向性猜測/待考」必須可見。
- 後世借名標記（朝鮮/會稽/泰山封禪等）不得被誤讀為定位證據。
- 神話層（十日、精衛填海、鯀禹洪水等）與地理層分開呈現。
- 圖片只用真實照片（已本地化 111 張），禁止 AI 生成圖。

## 6. 成功度量

- 發起人覆核效率：單條目覆核所需點擊 ≤ 2。
- 869 條目全部可達；45 張地圖全部可看；KG 4,334 節點全部有詳情頁或聚合歸屬。
