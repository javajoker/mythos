# 山海經 Web App — UI/UX 規格

> 版本 0.1（2026-10-26）。對齊 PRD 0.1。

## 1. 信息架構

```
首頁（世界地圖主視圖）
├─ 卷目錄（18 卷 × 子經）
│   └─ 卷頁（導覽 + 補丁圖 + 條目列表）
│       └─ 條目詳情（與地圖聯動）
├─ 實體庫（類型/搜索/類名聚合）
│   └─ 實體詳情（讀法 + 關係 + 出處 + 配圖）
├─ 裁決與發現（ADJ-002…005、F-0001…0012）
└─ 關於（方法、時代窗口、誠實性聲明、數據下載）
```

## 2. 主視圖（首頁）

- **畫布**：太平洋中心世界圖（`shanjing-overview.svg` 同源數據，SVG 渲染＋pan/zoom）。
- **圖層開關**（左上）：山經鏈（五經色族）｜框架書點（按狀態）｜現代參照點｜底圖地名。
- **右側欄**（選中時滑出）：條目/實體詳情卡。
- **底部時間說明條**：時代窗口 4000–1000 BCE 與「全部為競爭假說」常駐提示。
- **點位樣式**：●藍＝復用錨定、●金＝區域方向、□紅虛框＝待定錨；鏈＝色族實線，錨站＝雙圈。

## 3. 詳情卡（條目級）

自上而下：白話標題 → 原文（繁體，等寬襯線） → 白話解讀 → 現實候選（主候選＋對立候選，含現代山名⛰/水名💧） → 配圖（實拍，點開放大，註明來源） → 置信度徽章（很可靠🟢/較可靠🟡/方向性🟠/待考⚪） → 未決項（可折疊） → 相關裁決/借名/類名標記 → 連結（所在卷、相鄰條目、KG 關係）。

## 4. 實體庫

- 左：類型樹（山體 554／水體／地標／族群／人物神格／動物／植物／礦物資源／物件／天象／兆象）。
- 中：列表（名稱、讀法摘要、置信度、出現卷次）。
- 右：實體詳情＋「同類名實例」聚合（例：赤水 → 紅海/紅河/北方實例…——ADJ-005 類名頁）。
- 搜索：名稱/讀法全文；支持「九尾狐」「鹽池」「極光」直達。

## 5. 視覺語言

- 色系：紙本底色 `#f7f3e8`；五經色族沿用概圖（西紫/中紅/北金棕/東綠/南藍）；警示色：借名＝紫斜紋框、神話層＝灰藍斜體標籤。
- 字體：中文宋體系（原文）＋無襯線（解讀 UI）；原文與解讀視覺分層。
- 圖片：本地 `images/`（draft-v2 已本地化 111 張）；地圖 SVG 原樣引用適配目錄。
- 移動端：右側欄改底部抽屜；地圖雙指縮放。

## 6. 交互細節

- 點選鏈上站點 → 詳情卡定位到該站條目；點選框架書點 → 該點所在條目。
- 懸停顯示一句話摘要；長按/右鍵顯示「複製引用」（條目 ID＋引文）。
- 未決項與對立候選默認折疊但計數可見（「未決 3」）。
- 鍵盤：`/` 聚焦搜索；←→ 同卷上/下條目。

## 7. 無障礙與誠實性

- 置信度不得只用顏色（附文字）；所有對應附「競爭假說」常駐聲明。
- 圖片全部附 alt 與來源；配色對比度 ≥ WCAG AA。
