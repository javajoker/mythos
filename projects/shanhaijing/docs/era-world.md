# 山海經時代世界規格 v4 / SHJ Era-World Specification v4

> 時代窗口：**4000–1000 BCE**。本文件定義候選世界庫，不列出任何已預定的《山海經》對應答案。

## 1. 目的 / Purpose

時代世界庫為遮蔽語義判斷提供獨立候選。它描述候選在窗口內的形態、年代、分佈和狀態，而不是從《山海經》的待驗證解讀反向製造證據。

## 2. 必備內容 / Required content

| 類別 / Category | 必要屬性 / Required attributes |
|---|---|
| 自然地理與水體 | 位置、當時海岸或河道、靜態輪廓、相對位置、無方向連接、分支、尺度、年代與狀態 |
| 遺址與造物 | 靜態形狀、人工高台與陵寢格局、環繞與包含關係、尺度、材質、顏色、功能、朝向、建造與使用年代、遺跡狀態 |
| 動物與植物 | 形態、顏色、聲音、生態、當時分佈、滅絕或退出原分佈的時間 |
| 人群與文化 | 年代、習俗、生業、外觀、造物與一般性來源 |
| 天象與氣候 | 可見條件、週期、時代狀態與可觀測物理特徵 |
| 對立候選 | 同類、同時期、來自不同大區的可行對象，資料詳度盡量對稱 |

所有卡片只用一般性考古、古地理、古生物和氣候資料。不得引用對《山海經》的既有詮釋作為卡片證據。

## 3. 候選與地標共識 / Candidates and anchor consensus

1. 每個文本實體至少三個候選、至少兩個大區。
2. 候選卡先於評分建立並凍結版本；修改須記錄原因與雜湊。
3. 觀察原點不由單一城市或單一對應指定，而由多個可共同確認的地標及其關係反推。
4. 地標只有在獨立條目和關係形成一致支持後，才以穩定 ID 寫入 `anchors.jsonl`。
5. 共識形成前，不得用該地標排除其他候選；共識形成後仍需接受反例審查。

## 4. 比例尺與古環境 / Scale and reverse reconstruction

- 里數在 **0.35–0.42 km/里** 內擬合，每個模型保留取值和敏感度。
- 各篇先獨立，跨篇連接須有文本或已接受關係；總里程不是天然地理跨度。
- 古海岸與河道必須來自獨立古地理資料。
- 只有經獨立驗證的文本對應才能用於古環境反推；反推結果不得循環證明原對應。

## 5. 目前資料與缺口 / Current data and gaps

現有 `regions`、`region-properties`、`waters-era`、`fauna-era`、`cultures-era`、`courses` 與 `coastlines-present` 是種子資料，部分沿用現代世界資訊，尚未全部轉換成窗口內狀態。

尚需完成：

- 為每筆資料補齊 `from`、`to`、`state`、當時屬性與一般性來源；
- 移除窗口外出現的事物，保留窗口內可見的遺跡並標明狀態；
- 新建 `sites.jsonl` 與約前 2500 年代表時點的 `palaeo-coast.json`；
- 補齊對立候選並審查各地區資料詳度；
- 在有效圖譜形成前，不生成新的「時代地圖」。
