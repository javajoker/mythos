- `SHJ-05-1-016`：分段里程合計 937 里，篇末記 6,670 里；「白甘棗之山」的「白」是替代讀法候選。
- `SHJ-05-12-016`：base「凡十萬山」，明成化本作「凡十五山」；讀法仍須留下裁決記錄。
- 自動對勘發現 681 處 base 與兩個早期見證本不同、而兩見證本彼此一致的差異。它們只證明 base 偏離，不能由程序自動決定正式讀法。

## 4. 使用與裁決規則 / Usage and decision rules

1. 條目 ID 以 base 為穩定基準；工作文本次序以明成化本為準。
2. 當前 `working-text.jsonl` 的 base 讀法標為 `reading_status: unreviewed`，不得稱為全部確認的定本。
3. 自動分類只提供 `decision_status: proposed`；LLM 或人工裁決後才可改為 `decided`。
4. 裁決優先級為 **human > llm > auto**。每次覆寫保留理由、模型／審核者和版本。
5. 注疏只作轉錄，不進入原文事實圖或語義評分；現代編者內容只作為主張。
6. 路線與框架工具只讀 working text；working text 缺失時必須失敗，不得靜默退回 base。
