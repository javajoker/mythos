## 0. 前提 / Premises
- **文本**：只用原文；次序與讀法依明成化本（最早的完整見證本，[source-assessment](source-assessment.md)）；注疏（郭璞注等）不進入任何步驟。869 段。
- **時代窗口**：前 4000–前 1000 年（新石器晚期至商周青銅時代，[era-world](era-world.md) §1）。
- **原點座標**：中原（河南商都殷墟／洛陽一帶，約北緯 34.7°、東經 113.6°）。
- **全域宏觀文明網絡**：
  - 中原商周青銅文明、西南三星堆古蜀文明（都廣之野/建木/縱目人神權）。
  - 西亞蘇美/阿卡德、北非古埃及金字塔高台文明。
  - 美洲奧爾梅克（Olmec）與前古典期瑪雅（Pre-Classic Maya）階梯神廟與硬玉崇拜文明。
- **雙向研究**：正向語義對應 + 反向古氣候/古生物/古水網反演。

## 2. 宏觀尺度大對稱：東西兩大一萬八千餘里走廊

### 2.1 基準緯度與單位里
- 基準點：河南中原（$34.7^\circ\text{N}, 113.6^\circ\text{E}$）。
- 基準緯度帶：北緯 $30^\circ\sim 35^\circ$（1° 經度約 91.5–96.5 公里）。
- 初始單元里（周秦漢里）：**$1\text{ 里} \approx 0.4\text{ 公里}$**。

### 2.2 西向橫向長征走廊（西山經）
- 《西山經》四篇累計總里數：$4,360 + 4,140 + 6,744 + 3,680 = \mathbf{18,924\text{ 里}}$。
- 物理距離換算：$18,924 \times 0.4 = \mathbf{7,569.6\text{ 公里}}$。
- 精準吻合中原至埃及開羅的真實地表大圓幾何直線（$7,534\text{ 公里}$，誤差率 < 0.5%）。

### 2.3 東向縱向長征走廊（東山經）
- 《東山經》四篇全部清一色為筆直自北向南（「又南……里」），累計里數：
  $$\text{東次一（3,600）} + \text{東次二（6,640）} + \text{東次三（6,900）} + \text{東次四（1,729）} = \mathbf{18,869\text{ 里}}$$
- 物理距離換算：$18,869 \times 0.4 = \mathbf{7,547.6\text{ 公里}}$。
- **精確吻合北美洲落磯山脈與太平洋海岸山脈自阿拉斯加至墨西哥中美洲之南北縱貫總長度（約 7,500 公里）**！
- 東次二經、東次三經東側伴隨北美大平原（Great Plains），文本中無密集小水系阻隔，多為長距離跳躍的大平原邊緣山脈敘事。

## 3. 現象學轉譯與文明神物對照（R12）

1. **極晝極夜與極光** $\rightarrow$ **燭龍**（章尾山，身長千里，赤色，瞑為晦，視為明）：
   - 物理對照：北緯 65°–71° 西伯利亞/北冰洋極圈。赤色極光如巨龍蜿蜒；極晝極夜週期。三星堆凸眼縱目人面面具（柱狀眼）與此同源。
2. **神樹、十日與通天神柱** $\rightarrow$ **扶桑與建木**：
   - 物理與考古對照：
     - 四川成都平原三星堆青銅神樹（高 3.96 米，三層九枝，果上棲鳥，即「九日居下枝，一日居上枝」之實體再現）；
     - 東經 130°–145° 太平洋日出光學幻日折射；
     - 中美洲瑪雅吉貝世界樹（Ceiba）。
3. **大洋隱沒帶深海溝** $\rightarrow$ **歸墟／大壑**（八絃九野之水所注）：
   - 物理對照：琉球海溝至馬里亞納海溝（深 7000–11000 米），強大黑潮暖流交匯形成之無底深淵。
4. **階梯巨石高台與人工水網** $\rightarrow$ **崑崙九重之臺與弱水環之**：
   - 物理對照：開羅吉薩金字塔群與環陵港灣運河網、蘇美塔廟（Ziggurat）、秘魯卡拉爾階梯台基。
5. **氧化鐵紅砂海熱浪** $\rightarrow$ **炎火之山**（晝夜常明，投物輒然）：
   - 物理對照：撒哈拉東部大沙海（日光直射如火焰焚燒，地表逾 60°C）或西亞裂谷帶天然瀝青火泉。
6. **羽蛇神與玉石崇拜** $\rightarrow$ **海外東經神人操蛇與其陽多玉**：
   - 考古對照：中美洲奧爾梅克與瑪雅羽蛇浮雕、狂熱硬玉（翡翠）隨葬與祭祀習俗。
