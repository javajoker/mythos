## 0. 前提 / Premises
- **文本**：只用原文；次序與讀法依明成化本（最早的完整見證本，[source-assessment](source-assessment.md)）；注疏（郭璞注等）不進入任何步驟。869 段。
- **時代窗口**：前 4000–前 1000 年（新石器晚期至商周青銅時代，[era-world](era-world.md) §1）。
- **原點座標**：中原（河南商都殷墟／洛陽一帶，約北緯 34.7°、東經 113.6°）。
- **同名消歧原則（R15）**：以空間物理距離為同名合併與拆分的核心判準：
  1. **遠距同名拆分**：距離較遠的同名實體，視為不同實體（如埃及尼羅河黑水 vs 蜀地黑水 vs 幽都黑水；開羅吉薩崑崙 vs 絲路海內崑崙）。
  2. **近距跨卷合併**：近似地域不同經卷同名實體，視為同一實體（如西次三經崑崙與大荒西經崑崙 = 開羅吉薩；海內南經建木與海內經建木 = 三星堆神樹）。
  3. **爭議備註推進**：無法絕對解決的爭議點，記錄邏輯推理假說並加入備註，不阻斷管線推進，待全書解讀 draft 完成後集中覆核。
- **圖層架構與五臧山經坐標校準法則（Layered Architecture & Calibration Rule）**：
  1. **地理骨架層（《五臧山經》）**：前五卷以走向方位、巡行里數與水系閉環，建立全書唯一的客觀空間幾何與大地坐標基準網。
  2. **人文特產標註層（後續各卷）**：《海外經》、《海內經》、《大荒經》及《海內經終篇》描述邦國、神人、帝陵、特產風物與天文神話，本質是標註、疊加、補充於《五臧山經》地圖之上的人文地貌。
  3. **坐標強制校準**：後續章節的所有邦國、神祇、山川與奇異物產定位，必須嚴格以《五臧山經》已確立的空間幾何與地理坐標體系作為唯一校準基準。
  4. **衝突裁決由 LLM 承擔**：知識遷移與交叉驗證中的矛盾，純由 LLM 多維推理裁決，嚴禁用腳本抹平，裁決後回寫更新指定卷冊草稿並記全日誌。

## 2. 宏觀尺度大對稱：東西兩大一萬八千餘里走廊

### 2.1 基準緯度與單位里
- 基準點：河南中原（$34.7^\circ\text{N}, 113.6^\circ\text{E}$）。
- 基準緯度帶：北緯 $30^\circ\sim 35^\circ$（1° 經度約 91.5–96.5 公里）。
- 初始單元里（周秦漢里）：**$1\text{ 里} \approx 0.4\text{ 公里}$**。

### 2.2 西向橫向長征走廊（西山經）
- 《西山經》四篇累計總里數：$4,360 + 4,140 + 6,744 + 3,680 = \mathbf{18,924\text{ 里}}$。
- 物理距離換算：$18,924 \times 0.4 = \mathbf{7,569.6\text{ 公里}}$。
- 精準吻合中原至埃及開羅的真實地表大圓幾何直線（$7,534\text{ 公里}$，誤差率 < 0.5%）。

### 2.3 東向縱向長征走廊（東山經）
- 《東山經》四篇全部清一色為筆直自北向南（「又南……里」），累計里數：
  $$\text{東次一（3,600）} + \text{東次二（6,640）} + \text{東次三（6,900）} + \text{東次四（1,729）} = \mathbf{18,869\text{ 里}}$$
- 物理距離換算：$18,869 \times 0.4 = \mathbf{7,547.6\text{ 公里}}$。
- **精確吻合北美洲落磯山脈與太平洋海岸山脈自阿拉斯加至墨西哥中美洲之南北縱貫總長度（約 7,500 公里）**！
- 東次二經、東次三經東側伴隨北美大平原（Great Plains），文本中無密集小水系阻隔，多為長距離跳躍的大平原邊緣山脈敘事。
