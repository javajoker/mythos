## 0. 前提 / Premises
- **文本至上·拋棄後世注釋原則**：
  1. 只用原文正文；次序與讀法依明成化本（最早的完整見證本，[source-assessment](source-assessment.md)）。
  2. **徹底拋棄漢魏郭璞注、清代經學考據與現代一切將《山海經》微縮於一省一隅的狹隘注釋與解讀！**
  3. 嚴格、純粹從《山海經》原始經文字面出發，以大地測量學、古水文與地質客觀事實為唯一檢驗標準。
- **時代窗口**：前 4000–前 1000 年（新石器晚期至商周青銅時代，[era-world](era-world.md) §1）。
- **原點座標**：中原（河南商都殷墟／洛陽一帶，約北緯 34.7°、東經 113.6°）。
- **【無新地理實體公理】(Zero-New-Geography for Books 6–18)**：
  1. **《五臧山經》（卷一至五）是全書唯一的地理空間底座**：確立全部山川走向、方位里數與發源注入水系網絡骨架。
  2. **卷六至卷十八純屬人文與物產，絕對沒有新的地理內容**：後續十三卷只描述邦國、神人、先賢帝陵、特產風物、異獸靈木與科技發明。
  3. **山水實體 100% 複用五臧山經**：所有卷六至卷十八提到的山、水、澤、海實體（如崑崙、不周、凶桑、衡山、巫山、幽都、方丈、蓬萊、羽山、首陽、赤水、黑水、弱水、江水、河水、洋水、東海、西海、南海、北海等），**一定在《五臧山經》中找到對應，並且強制 100% 複用《五臧山經》已確定的地理坐標與實體節點**！絕不允許在知識圖譜或地圖中為後續卷建立漂移獨立的重複地理節點。
  4. **地圖表現法則**：反應到地圖上，也是把對應的人文物產添加到已有的五臧山經地圖之上：根據描述的五臧山經地理位置，補充人文和物產圖層。
- **經典實證鐵律（以西山經與大荒西經為例）**：
  1. **崑崙之丘**：《大荒西經》的崑崙之丘與《西山經》完全一致，**嚴格對應於埃及開羅吉薩高地金字塔群**（30.0°N, 31.2°E），實惟帝之下都，高萬仞，面有九門。
  2. **地中海與非洲板塊**：自中原一路向西，《西次三經》自帕米爾天門向西橫貫西亞兩河，進入地中海、埃及與北非板塊。
  3. **赤水 ≡ 紅海 (Red Sea)**：環繞崑崙、西南流入南海之赤水，100% 複用為紅海。
  4. **黑水 ≡ 尼羅河 (Nile River)**：自崑崙流出西南入海之黑水，100% 複用為古埃及尼羅河（古埃及名 *Aur*，意為黑水/黑河）。
  5. **神陸吾 / 開明獸 ≡ 獅身人面像 (Sphinx)**：人面虎身九尾虎爪守衛帝之下都九門，100% 複用為吉薩獅身人面像。
- **衝突裁決由 LLM 承擔 (Conflict Handling by LLM)**：
  - 知識遷移與交叉驗證中的矛盾，純由 LLM 多維推理裁決，嚴禁用腳本抹平，裁決後回寫更新指定卷冊草稿並記錄於日誌。

## 2. 宏觀尺度大對稱：東西兩大一萬八千餘里走廊

### 2.1 基準緯度與單位里
- 基準點：河南中原（$34.7^\circ\text{N}, 113.6^\circ\text{E}$）。
- 基準緯度帶：北緯 $30^\circ\sim 35^\circ$（1° 經度約 91.5–96.5 公里）。
- 初始單元里（周秦漢里）：**$1\text{ 里} \approx 0.4\text{ 公里}$**。

### 2.2 西向橫向長征走廊（西山經）
- 《西山經》四篇累計總里數：$4,360 + 4,140 + 6,744 + 3,680 = \mathbf{18,924\text{ 里}}$。
- 物理距離換算：$18,924 \times 0.4 = \mathbf{7,569.6\text{ 公里}}$。
- 精準吻合中原至埃及開羅的真實地表大圓幾何直線（$7,534\text{ 公里}$，誤差率 < 0.5%）。

### 2.3 東向縱向長征走廊（東山經）
- 《東山經》四篇全部清一色為筆直自北向南（「又南……里」），累計里數：
  $$\text{東次一（3,600）} + \text{東次二（6,640）} + \text{東次三（6,900）} + \text{東次四（1,729）} = \mathbf{18,869\text{ 里}}$$
- 物理距離換算：$18,869 \times 0.4 = \mathbf{7,547.6\text{ 公里}}$。
- **精確吻合北美洲落磯山脈與太平洋海岸山脈自阿拉斯加至墨西哥中美洲之南北縱貫總長度（約 7,500 公里）**！
- 東次二經、東次三經東側伴隨北美大平原（Great Plains），文本中無密集小水系阻隔，多為長距離跳躍的大平原邊緣山脈敘事。
