# 山海經時代語義對應規格 v4 / SHJ Era-Semantic Specification v4

> v4.0 · 2026-10-21 · 實作 [研究框架 v4](../../../docs/research-framework.md)。
> 本文件是《山海經》專用流程的唯一權威規格；其他文件不得複製出不同版本。

## 1. 專用設定 / Corpus settings

| 設定 / Setting | 第一版規則 / v1 rule |
|---|---|
| 時代窗口 | **4000–1000 BCE**；不同段落可分屬窗口中的不同時期。 |
| 地理範圍 | 全球均可生成候選；任何具體對應都是競爭假說，不是前置答案。 |
| 比例尺 | 周秦漢里以 **0.35–0.42 km/里** 為候選區間；逐模型記錄取值、擬合與敏感度。 |
| 篇段模型 | 各篇先獨立；只有原文或已接受關係能建立跨篇連接。不得直接把總里程當地理跨度。 |
| 初始化錨點與觀察原點 | 未確認候選可作 `initialization` 錨點啟動正向或反向擬合，沒有證據優先權且可校準、替換或否決；最終原點由多個共同確認地標形成共識後寫入 `anchors.jsonl`。 |
| 第一版地理約束 | 《五臧山經》（卷一至五）是唯一首批地理節點來源；卷六至十八的 `MTN/WAT/LND` 必須複用其節點。 |
| 無法復用 | 建立 `pending_anchor` 提及與衝突，交 LLM 裁決；程序不得自動新建節點或指定對應。 |

第一版的强制復用只約束圖譜結構，不代表任何崑崙、赤水、黑水或其他實體已經獲得現實地理結論。後續版本是否放寬，須另行決定。

## 2. 迭代管線 / Iterative pipeline

| 階段 / Stage | 工作 / Work | 產物與退出條件 / Output and gate |
|---|---|---|
| 0 工作文本 | 校勘三個見證本，固定條目 ID、明成化本次序和讀法裁決狀態 | `entries.jsonl`、`working-text.jsonl`、校勘記錄；用於證據的讀法必須已確認 |
| 1 實體抽取 | 由 LLM 從工作文本抽取全部實體、提及、名稱語義與文本關係；後續卷地理提及可暫存待錨定 | `nodes/mentions/edges`；每段有覆蓋結果，未抽取項顯式列出 |
| 1.5 全量水體映射 | 由 LLM 為每個水體建立真實世界候選、共享山體關係和歷史狀態，先交項目發起人確認 | `water-mappings.jsonl` 全量無遺漏；改道、消亡、沼澤化與遺址均有狀態記錄 |
| 2 地理語義擬合屬性 | 水體映射確認後，名稱遮蔽下生成至少三個候選、至少兩個大區；逐屬性評分，加入時代、坐標、形態、水文等待審屬性 | `candidates/judgments/anchors` 與 `attributes`；沒有對立候選不得標為接受 |
| 3 初版圖譜 | 合併文本事實和目前有效的語義擬合屬性，執行結構與引用校驗 | **KG v1**；文本事實與假說分層，無無主引用 |
| 4 五臧山經草稿 | 逐條完成前五卷的原文、實體展開、候選解釋和未決項 | `deliverables/draft-v1/` 前五卷；不強迫每段都有確定對應 |
| 5 補充屬性圖譜 | 加入圖騰與文化聯想、生態與材料等演繹屬性，保留推理來源與可信度 | 更新 `attributes`；`associative/deductive` 不得冒充原文屬性 |
| 6 後續經卷 | 完成卷六至十八草稿；第一版地理提及只復用五臧山經節點，無法對齊者進入衝突 | 後續卷草稿與待錨定清單 |
| 7 更新圖譜 | 加入後續卷人文、物產、天象實體和屬性，補上地理復用與人文錨定關係 | 更新版 KG；覆蓋、類型和第一版地理約束通過 |
| 8 LLM 衝突解決與合併 | LLM 判斷合併、拆分、異文、視角互補或草稿修訂；程序只執行已裁決的變更 | `conflict-decisions.jsonl`、`findings/conflict-resolutions.md`、受影響產物更新 |
| 9 迭代與交付 | 對受影響範圍重跑階段 1–8，再做紅隊、完整性和可信度審查 | 無阻斷衝突後形成 `draft-v1`；地圖另行由有效圖譜重建 |

## 3. 地理語義擬合 / Geographic semantic fitting

統一推論順序為：**原文證據 → 靜態形狀與物理特徵 → 古代通用詞義 → 同時代候選 → 相同寬容下的吻合與矛盾 → 可信度和未知項**。

1. **輸入遮蔽**：以代號替代實體名，只保留原文描述、名稱語義、關係摘要和必要的觀察框架。
2. **靜態形狀優先**：先提取輪廓、相對位置、連接、環繞、包含、分支與分佈；動態「出、入、注」在候選比較中可降為無方向連接。
3. **候選競爭**：至少三個候選、至少兩個大區；候選卡附年代、狀態、物理屬性和一般性來源。
4. **逐項判斷**：外觀、顏色、尺度、材質、功能、聲音、生態、方位、年代分別記錄分數、證據與理由；現代水流、後世地名、傳播鏈缺失和現代狹窄物種分類不得單獨否決。
5. **比例尺敏感度**：在 0.35–0.42 km/里區間比較結果；區間內的相似不得單獨證明跨篇連續路線。
6. **初始化與校準**：未確認候選可作 `initialization` 錨點，從指定篇段正向或反向啟動搜索；它不增加證據權重，必須可校準、替換或否決。支持時可加入多個錨點聯合求解，最終觀察原點才由共同地標與關係形成共識。
7. **輸出屬性**：語義擬合結果寫成 `semantic_fit` 屬性，狀態為 `proposed`；經衝突處理與審查後才可改為 `accepted`。

## 3.1 全量水體映射與歷史狀態 / Complete water mapping and historical states

- **無遺漏**：每個 WAT 節點都必須在 `water-mappings.jsonl` 中有記錄。代碼只負責核對數量，LLM 負責全部候選、映射、共用關係與語義判斷。
- **共享水體**：同一水體可被多個山體共用，`shared_mountains` 與關係 ID 必須保留，可作跨山系的語義錨點，不得因多山共水或同名而自動拆分。
- **人工確認順序**：先由 LLM 完成全部水體映射並由項目發起人確認，再進入其他初始化錨點的聯合校準。
- **歷史狀態**：候選必須考慮改道、消亡、萎縮、洪水與枯水交替、沼澤化、人工渠道遺址、水質或含沙量改變；不知道時標 `unknown`，不得用現代水文直接否決。
- **弱水示例**：「環狀弱水」可保留為環狀人工運河遺址及其後續沼澤化、淤積或水量衰減的競爭假說。須比較環狀形態、遺址年代、水文演變與其他自然水體候選，不能因今天不是天然大河而排除。

## 3.2 語義指稱差異與聯動配置 / Referent distinctions and linked configurations

- 同名或共享詞根不自動代表同一對象。`昆侖之丘`、`昆侖／昆侖山`、`昆侖之虛／昆侖虛` 與 `西胡白玉山` 必須分別記錄 scope，再由 LLM 決定合併、部分重合或拆分。
- 水體名可指代不同河段、支流、替代讀法或歷史消失部分；不得把 `河`、`河水`、`黑水`、`洋水` 強制合成一條完整現代河道。
- 一個初始化候選可帶出多個配合錨點，但每個水體、地貌和山體仍需獨立映射；聯動配置只表示待檢驗的一致性組態。
- 吉薩聯動配置、阿特拉斯山脈、撒哈拉之眼與乞力馬扎羅等古今綜合聯想，只能由 LLM 以證據推理提出並審核，不得由字符串、名稱或程序附會生成。
- 後續卷未抽取的指稱先登記於 `semantic-referents.jsonl`，不建立現實坐標節點。

## 3.3 對立候選硬性要求與遮蔽對照 / Rival candidates and masked re-judgment（G-1／G-2，2026-10-27 紅隊增補）

- **對立候選硬性要求**：每條映射至少記一個**已測試**的對立候選，或書面說明何以無對立；補不出對立候選的條目置信度**封頂 low**。零對立候選視為「沒有去找」而非「沒有競爭者」。
- **遮蔽對照流程**：對每鏈抽樣 3–5 段（覆蓋高置信與關鍵錨段），抽去經名與前後鏈，僅給實體清單讓 LLM 獨立定位，再與現有映射比對，記錄一致/分歧率；分歧段降置信並入待裁。遮蔽重判結果寫入該經 findings。

## 3.4 station-grid 定位規則 / Grid as negative tool（G-3，2026-10-27 紅隊增補）

- 網格是**否定工具，不是肯定工具**：候選偏離網格帶太遠則否；網格點不得直接作候選位。
- station-grid 輸出改為「**經度帶 ± 容差**」而非點位；端點釘死反推邏輯（先定起訖再均攤中間站）產生的中間站坐標是算術產物，不作證據。
- 映射以**文本實體為準**、以網格帶為檢核；二者衝突時記 conflict 並列三值（適配表/網格/文本重配），不得靜默取其一。

## 3.5 里程裁決模板 / Mileage adjudication template（G-4，2026-10-27 紅隊增補）

- 每鏈**事先聲明**：所用里值檔位（0.35–0.42 區間內）、允許區間、方向約定（弦距 vs 路徑距）。
- 單鏈內部逐腿偏差超 **±50%** 者必須分段解釋；**總帳對沖無效**；層累只解釋放大（注水），**不解釋縮水**——縮水即起訖錨或鏈屬錯誤的信號，記反例而非 variant。
- 里程展示一律**三檔帶符號並列**（0.35/0.385/0.42），不得只展示最有利檔；負偏差不得寫成「吻合度」。
- 撤回一切對 F-0008 未載數值的引用（「1.2× 下限」係虛構出處）；文檔中「F-0008 允許 ××」表述逐一核對原文。

## 3.6 物理／天文硬約束清單 / Physical and astronomical hard constraints（2026-10-27 紅隊增補）

- 「**冬夏有雪**」：需海拔或緯度支持窗口期常年積雪；平原站位為硬否決（窗口期氣候略暖不改此判據）。
- 「**正立無景**」：約束的是約 47° 寬的緯度帶（回歸線上一年一次、以南一年兩次），辨別力低；單一站點不得以此自稱「物理上唯一自洽」。
- 「**觀察者缺席**」：文本自稱觀察記錄，候選區域在窗口期無人類活動證據者為鏈段硬否決（與物種判據同級）。

## 3.7 算術鏈與命名鏈分歧信號 / Arithmetic-vs-named chain divergence（RT-B20，2026-10-27 紅隊增補）

凡純算術鏈與命名候選偏離 **>3° 經度**者，視為**今名污染信號**，強制補一輪「去今名」重判：遮蔽今地名，僅用實體屬性與水系拓撲重配。分歧本身必須記錄，不得只採其一。

## 3.8 對照表降格規則 / Appendix table demotion（G-5，2026-10-27 紅隊增補）

附錄對照表降格為**山系段粒度**（「本鏈對應××山系」），不列單站點位；單站信息以正文置信度為準。對照表不得越過正文置信度呈現精度。

## 4. 第一版地理復用與人文錨定 / v1 reuse and anchoring

- 卷一至五可建立 `MTN/WAT/LND` 首發節點，ID 依 `docs/conventions.md`。
- 卷六至十八的地理提及使用 `pending_anchor` 或指向既有地理節點，不建立新的地理節點。
- `POL/PER/CRE/PLA/MIN/OBJ/AST/CLIM` 可建立新節點，透過 `anchored_to` 關係連到五臧山經地理底座。
- 遠距同名拆分、近距跨卷合併由 LLM 依 R15 裁決；若拆分會違反第一版無新地理約束，結果必須保留為衝突，不能由程序繞過。
- 合併後保留首發節點 ID；名稱、異體和所有提及進入別名與提及記錄，不因改名改寫歷史 ID。
- **置信度繼承**：復用/依賴節點的置信度 **≤ 被復用/被依賴節點**的置信度（framework 發現 11＋zhongci E1）；框架未決時點位不得高於 pending 級；凡依賴 pending 錨者置信度自動封頂，並建錨依賴圖標記單點失效風險。

## 5. 屬性與語義擴展 / Attribute extensibility

- `textual`：原文直接陳述的屬性。
- `semantic_fit`：文本描述與時代候選之間的擬合屬性。
- `associative`：圖騰、宗教、文化流變等聯想假說。
- `deductive`：生態適應、材料用途、工藝與其他演繹假說。

不同實體類型使用不同 predicate 與關係約束，機器可讀定義見 `data/kg-ontology.json`。新增語義時先註冊 predicate、適用類型、值類型與證據要求，不得把任意解釋塞入固定備註欄。

## 6. 衝突裁決 / Conflict resolution

程序可發現重複值、引用錯誤、類型不符、里數差異和未錨定提及，但不得決定語義對錯。LLM 的每個裁決必須包含：

- 衝突涉及的實體、屬性、原文與候選值；
- 對立解釋及至少一項反向證據檢查；
- `merge`、`split`、`accept_variant`、`keep_both`、`revise` 或 `unresolved`；
- 理由、模型、提示版本、輸入雜湊與審核狀態；
- 需要更新的具體圖譜記錄和草稿條目。

人工覆核優先於 LLM，LLM 裁決優先於自動提議；自動程序只檢測和執行，不擁有語義裁決權。

### 6.1 對稱性檢查 / Symmetry check（G-6，2026-10-27 紅隊增補）

- 同一判據對主候選與對立候選的適用必須**並列展示**；不對稱適用必須給出理由，否則判據作廢。
- **晚出層**對主候選與對立候選一律不作定位證據，僅作流變註記；晚出層正證用法全庫掃描降格。
- **物種證據**：窗口期分布帶寬數千公里的物種（如 4000–1000 BCE 的犀象）屬**非定位性證據**——只能用於否決（窗口期不可能區），不能用於釘點；全庫對稱適用。
- **祠牲證據**：在 F-0019 祠牲簇二選一裁決前，祠牲句一律不作定位證據（雙向）。
- **俗名證據**：今名俗名層（如「Big Muddy」）與窗口期無涉，全庫清除，不得正證或反證。

### 6.2 抽取與合併的裁決紀律 / Extraction and merge discipline（xici C13，2026-10-27 紅隊增補）

- **否定句不生成實體節點**（「無水」不得抽成 WAT 節點）。
- **合併節點須有裁決記錄**（ADJ/F 項引用），程序不得自動合併。
- **類名規則性狀判據硬要求**：赤水/黑水/流沙等類名實例必須附性狀判據（水色/含沙/季節性紅濁的實測或文獻依據），無則不得登記實例；類名規則須有可證偽的否決實例（赤水實例膨脹教訓）。
- **範疇檢查**：系譜人名不作地理水體（「赤水之子聽訞」屬 PER 非 WAT）；抽取時對 PER/WAT 範疇逐例檢查。

### 6.3 裁決執行五步閉環 / Five-step adjudication closure（framework 發現 1，2026-10-27 紅隊增補）

每項裁決必須走完：**裁決 → 受影響記錄清單 → 逐條回寫 → 計數覆核 → 對外陳述覆核**。裁決已下而回寫不全（含 coverage 頭條等對外陳述）視為未完成裁決。

## 7. 對崑崙假說的直接推論 / Direct consequence for the Kunlun hypothesis

此前以水流方向、後世中國水系名稱、傳播鏈缺失或獅虎物種差異否定開羅／吉薩的論證，不再作為有效否決依據。

開羅／吉薩可以繼續作為崑崙之丘的**競爭候選與未確認初始化錨點**，從《西次三經》反向擬合五臧山經的現實位置；它只啟動演算法，沒有證據優先權，也不能因此直接確認。支持時可加入更多初始化錨點，在後續推理中聯合校準、替換或否決。

後續主要比較其靜態地理形狀、人工高台與陵寢格局、人面獸身造像及其他同時代物理特徵，並與其他候選使用完全相同的古代通用詞義、寬容規則、證據要求和紅隊程序。傳播機制未知時標為未知，不編造接觸者、路線或動機。

## 8. 目前狀態 / Current state

舊草稿、舊地圖和舊解釋圖已清除。新實體圖譜、草稿、語義判斷與地圖均待依本規格生成；時代世界庫仍是種子資料，紅隊尚無新版本的審查記錄。
