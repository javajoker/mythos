## 3. 水系統配置

```
北受水（洛）：甘水→北→洛｜虢水→北→洛｜滔雕之水→北→洛｜浮濠之水→西→洛（流向疑點）
南受水（伊）：滽滽之水→南→伊水（全鏈唯一南注——洛/伊分水嶺在釐山—箕尾之間）
西端閉合：雒水（讙舉之山出）→東北→玄扈之水（與中五共享水體錨點）
洛域閉合：「此二山者，洛閒也」——牡山/讙舉之山＝洛域西界
```

洛/伊雙受水＋多水匯流（四溪注洛）是範圍判定的第一證據（不依任何名稱成立）：北受水四溪同注一「洛」、南受水一溪注「伊」，鏈條中段跨洛/伊分水嶺——豫西洛陽—嵩縣—欒川—盧氏走廊的拓扑自證；西端「洛閒」閉合把鏈尾鎖在洛河上游（商洛—洛南方向）。

## 4. 人文風物與時代狀態

- **生業作物**：漆＋椶（熊耳之山）——漆樹/棕櫚種植利用；竹叢雙類（竹箭/竹䉋，牡山）。
- **毒魚知識雙記**：茇（柄山，如樗葉如桐而莢實）、葶薴（熊耳之山，如蘓而赤華）——「可以毒魚」的漁獵技術記錄，集中於本經中段。
- **人魚＝大鯢候選**（浮濠之水）——洛河流域歷史大鯢分布與「多人魚」相容。
- **礦產帶**：玉金（鹿蹄）、礝瓀雙石（扶豬）、玉銅（柄山）、金玉＋青雄黃（白邊）、水玉（浮濠之水）、㻬琈之玉（箕尾）——豫西—陝南多金屬礦帶方向相容（不作單獨證據）。
- **造像誇張群**：䴦（如貉而人目）、犀渠（如牛蒼身、音如嬰兒、食人）、𤢺（如獳犬有鱗、毛如彘鬣）、馬腸之物（玄扈之水）。
- **禮制（總結段）**：九山「其神狀皆人面獸身」＝統一神格造像（人面獸身）；祠「毛用一白雞，祈而不糈，以采衣之」——白雞犧＋不糈＋采衣的輕祭規格（對比中五的冢/䰠/合天三級重祭，本經為輕祭鏈）。
- **時代演化**：無消亡水體記錄；全部水體 living。

- **跨鏈共享水錨點（E1：降 pending 依賴）**：玄扈之水（中四讙舉之山「雒水東北流注」×中五陽虛之山「臨于」）——中四/中五兩終點互相鎖定：讙舉（110.1°E 34.0°N）在西南、陽虛（110.6°E 34.4°N）在東北，與「雒水東北流注于玄扈之水」的無方向連接相容。**但兩錨經一條未確指的水互相支撐、無外部固定點（錨級聯）——玄扈之水確指（F-0020）前均懸空，置信度封頂 medium**。
