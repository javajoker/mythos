# 卷12・海內北經 逐條目四段式分析

- 範圍：SHJ-12-1-001 … SHJ-12-1-027（27 條目，依 `reference/shanhaijing/text/12-海內北經.md` 清本）。
- 時代窗口：4000–1000 BCE。假設級別：L1＝文本內互證；L2＝跨文獻/考古互證；L3＝結構推測。
- 版本說明：傳世本《海內北經》開首的「蛇巫之山／西王母／三青鳥（在昆侖虛北）」與卷末的「蓋國在鉅燕南／倭／朝鮮在列陽東／列陽屬燕」諸條，**不在本清本之內**（本清本自「海內西北陬以東者」起、至「孟鳥」止）。本卷分析僅覆蓋清本 27 條目；西王母—三青鳥母題已由西三玉山（錫瓦綠洲，MTN:SHJ-02-3-011#1）體系承載，朝鮮／列陽／蓋國／鉅燕屬借名層，若後續版本補入應按借名警示處理。
- 復用約定：復用山經節點寫節點 id；新增實體標「新增」；借名警示＝名稱層晚於時代窗口，不作定位依據。
