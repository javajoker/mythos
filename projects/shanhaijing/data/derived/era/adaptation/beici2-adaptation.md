## 0. 方法與約束

- **名稱永不作錨**：管涔/汾/晉水/鴈門/北嚻等借名標記——但**水系拓扑獨立成立**（汾河西南注黃河中游＋支流東向入汾扇形）。證據順序：水系拓扑→山勢走向→人文風物。
- 錨點：**終點拓撲錨**——敦題之山（51.5°N, 105.0°E）「是錞于北海」＝貝加爾湖南岸方向；**北冰洋讀法**（晉北→北冰洋海岸）里程過遠且無雙證，降為對立候選。起點弱錨：管涔之山「在河之東，其首枕汾」＝晉北呂梁方向（借名警示）。
- **發起人裁定補充**：黃河改道主要影響下游——「河」僅錨定中游穩定段；以下游變遷否決候選或鎖定候選均不許可。
- 里程：自記 5,690 里 vs 腿程 5,590 里（-1.8% variant）；晉北→貝加爾實距約 1,600 km vs 腿程≈2,152 km——**層累約 1.34×（F-0008 帶內）**；網格起點（34.0°N, 106.4°E＝隴東）為算術後置差異，擬合取晉北—呂梁。
- 時代窗口 4000–1000 BCE。

## 3. 水系統配置

```
汾水系統（借名但拓扑成立）：
  汾水（管涔·西注河）← 酸水（東注）← 晋水（東南注）← 勝水（東北注）
  ——汾河西南注黃河中游＋三支東向入汾的扇形（晉中盆地）
河＝黃河中游晉陝峽谷穩定段（下游改道不否決）
伏流：鮪水（白沙山出上潜下——與中十一求水同型）
內陸湖澤：旄水→印澤；涔水→邛澤；湖灌之水→海（岱海/呼倫湖候選）
終點：錞于北海＝貝加爾湖（終點拓撲錨）
```

## 4. 跨經與跨卷證據

- **冬夏有雪三見**（狂山 007／姑灌 013；北一-015 小咸之山）——高寒積雪帶重複出現，與生食不火人群（北一-026／北三-048）構成北方生業證據群。
- **𩣡馬一角**（009）與北一-003 䑏疏一角——獨角獸母題兩見（角馬/藏羚角突觀察泛化）。
- **狍鴞**（010）：羊身人面、目在腋下、虎齒人爪、食人——全書著名食人神獸（人面母題＋食人警戒風物）。
- **三桑無枝巨木百仞**（015）：巨針葉樹/古樹記錄（「無枝」＝樹形觀察——巨杉類？確指待考）。
- **白沙山「廣員三百里盡沙也」**：沙地尺度記錄（毛烏素沙地/大同盆地沙質帶——地貌證據級）。
- **文明同域**：晉北—陰山農牧交錯帶（仰韶晚期—龍山方向）→ 蒙古—貝加爾（鹿石/石板墓文化方向，窗口內）——同域候選級；古愛斯基摩/西伯利亞傳統由北一/北三承載。
- **借名群**：管涔/汾/晋水/鴈門/北嚻——後世以文本名命名山西地理的典型案例（因果倒置警示：不得由今名反證本經位置）。
