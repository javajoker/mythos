## 0. 方法與約束

- **名稱永不作錨**：會稽/羽山/區吳/鹿吳/漆吳/堯光/咸陰/苕水/具區——與中國名物同名者一律借名標記。證據順序：水系拓扑→山勢走向→人文風物。
- 錨點：**起點拓撲錨**——柜山（24.8°N, 103.8°E）＝滇東高原（昆明—曲靖方向）：「英水出焉，西南流注于赤水」——**赤水＝紅河水系方向**（滇東的西南向大河 ✓ 強拓扑；赤水與西三赤水＝紅海共名，共名標記 F-0011 規則）。
- 文明框架：南島方向——本經＝雲貴—南嶺—東南沿海—東海島鏈；**南島語族起源帶（大坌坑文化，台灣—閩台，5000–4000 BP，窗口內）同域評估**見 §4。
- 里程：自記 7,200 里 vs 腿程 7,210 里（+0.1%——文本完全自洽）；0.385 檔≈2,776 km vs 滇東—浙閩沿海實距約 2,000 km——**層累約 1.4×（F-0008 帶內）**；原始腿程終點落 130.8°E（琉球南）——東海島鏈延伸記 variant。
- 時代窗口 4000–1000 BCE。

## 3. 水系統配置

```
赤水（＝紅河方向）← 英水（柜山·西南注）——西南向拓扑錨
具區（北望大澤）← 苕水（浮玉·北注）——北向入澤
南流系統：𨴯水→虖勺；勺水→湨；湨水→列塗（嶺南南向河）
滂水系統（東向入海）：滂水（虖勺·東注海）← 鹿水 ← 澤更之水（三溪匯滂）
東海（漆吳——島鏈終點）
```

## 4. 跨經與跨卷證據

- **赤水共名**：南二赤水（紅河方向）vs 西三赤水（紅海）——共名標記（F-0011 規則），各自本地落實。紅海讀法已檢驗否決（希賈茲起點→東向鏈橫渡波斯灣無水行記錄；與西二/西三覆蓋衝突；柜山丹粟＝滇黔桂丹砂帶相容）。
- **南島語族起源帶**：本經東段（閩台—東海島鏈）＝大坌坑文化同域（5000–4000 BP，窗口內）——漆吳之山「處于東海」的島鏈端點與南島擴散起點方向相容——**同域候選級**（文化斷層保持未知）。
- **貍力土功兆（001）**：「其縣多土功」＝土建賦義（與東二鵹鶘同型）；**鴸「其縣多放士」**＝流放者人群記錄（人文風物）。
- **猾褢穴居冬蟄（003）**：穴居＋冬眠——熊類泛化候選（華南熊）。
- **神群龍身鳥首**：與南一鳥身龍首互為鏡像（鳥/龍母題位置互換）——兩經神群對仗。
- **「四方而三壇」（成山 008）**：方形山＋三級台地——若為人工壇則為全書罕見的「人造地形」記錄（待裁——遺址與造物類）。
