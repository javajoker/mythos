## 3. 水系統配置

```

  洈水（宜諸之山）→南→漳水（荊山）→東南→雎水（景山）→東南→江（長江）

中段（桐柏—豫南，6–14 站）：無新水系記錄；漳淵（光山，計蒙所遊）＝**雙向記錄（E3）**：①神話地理延用（主線讀法）；②漳淵同名異淵→光山段距西段漳水 500+ km，光山段位置存疑、中段定位鬆動——兩讀並列，不許單向吸收
東段（皖西—大別，15–23 站）：郁水（讙山）出而潛流（伏流，無受水記錄）
```

西段水系是範圍判定的決定性拓撲：東南入江＋三級嵌套只能位於長江北岸（江漢平原北緣）——與起點錨（保康方向）互證，不依「荊山/雎水/漳水」任何同名成立。**E2 更正（2026-10-27）**：中東段 6–14 站零水系記錄，此前以「桐柏—大別分水嶺脊線行走，脊線無大河可記」辯護——**此辯護與事實不符，撤回**：桐柏山是淮河、唐河、白河支流源區，大別山為淮河源群，脊線恰是多河發源處；按窗口期水文（全新世中期降水高於今，古河道遺存如流沙層/古湖盆可為證），窗口期該區水系只會更密——**不得以「無河」辯護有河文本的時代背景**。同區域的中十一記了 12+ 條水系（視水一源五支等），兩鏈同域（信陽—大別）一密一疏，密度差未解釋——**記為未解異常**；中八中段是否為後世插入層，交 textual-critic。

## 4. 人文風物與時代狀態

- **神群統一格式**：總結段「其神狀皆鳥身而人面」——**全經 23 山神同屬鳥身人面神群**（與中二「人面鳥身」神群可比，方向相反待裁）；另有具象神三尊：𧕛圍（人面羊角虎爪，居雎漳之淵，出入有光）、計蒙（人身龍首，居漳淵，出入飄風暴雨）、涉𧕛（人身方面三足）——**龍首神＋風雨隨神**為氣候賦義記錄。
- **祭祀等級**：驕山＝冢（羞酒少牢祈瘞，嬰毛一璧）；通祭＝雄雞祈瘞＋藻圭＋糈用稌——兩級祭儀，冢級位於水系匯流處（雎漳之淵旁），祭祀重心與水系拓撲耦合。
- **物產帶**：丹粟（景山）、黃金/鮫魚（漳水）、白玉（洈水）、金銀鐵（銅山——桐柏多金屬礦帶方向）、赤錫/白錫（龍山/讙山）、赭（若山/仁舉）、堊（陸䣀/衡山雙色）、砥礪（讙山/師每）；林果群（綸山柤粟橘櫾、靈山桃李梅杏——**C1：橘櫾屬窗口期非定位性證據，只能否決不能釘點；待 T-RT17**）；染料/織材（柘多見於 17–23 站）。
- **動物群**：犛牛（荊山——高原種出現於鄂西；**C2：窗口期非定位性證據，記張力項，不作定位證據；待 T-RT17**）、兕牛/白犀（美山/琴鼓——犀類記錄；同屬非定位性證據——全新世大暖期犀象北界達黃河流域，只能用於否決不能用於釘點）、閭麋麖麂麢㚟鹿群、白鷮翟鴆雉群；**文魚**（雎水——書內罕見魚種）。
- **時代演化**：無消亡水體記錄；郁水伏流為岩溶水文記錄；漳淵空間矛盾（光山遠離漳水）**雙向記錄（E3）**：①神話地理延用（主線）；②同名異淵→光山段位置存疑（對立）——兩讀並列待裁。

## 4A. T-RT05 遮蔽重判（2026-10-28）——景山—荊山—驕山段遮蔽一致，解封

- **方法**：盲評評審在無先驗（不知本項目映射）下，僅據經文獨立重判本鏈。
- **盲評結論**：評審獨立得出「**鄂西荊山—沮漳河**」讀法——雎水＝沮河、漳水＝漳河（二水名存至今且相匯）、荊山名存至今、橘柚＝亞熱帶標誌物產；犛牛（高原種）記為**層累噪點**。盲評置信：高。
- **比對與落實**：
  - **景山遮蔽一致 → 解封**：confidence medium→**medium_high**（conflicts 留痕「T-RT05 遮蔽一致解封（2026-10-28）」）——盲評沮漳河系判讀與本站雎水東南注江起點錨（洈→漳→雎→江三級嵌套）逐項對應。
  - **荊山遮蔽一致 → 解封**：confidence medium→**medium_high**（同上留痕）——盲評漳水＝漳河＋橘柚亞熱帶標誌與本站漳水東南注雎＋橘櫾竹記錄對應；犛牛盲評記層累噪點，與本站 C1/C2 非定位性證據處置相容。
