> 依 `docs/era-world.md` 與 skill `era-world-modelling` 建立。資料只用一般性考古、古地理、古生物與氣候來源，不用對《山海經》的既有詮釋。

## 使用限制 / Usage gate

在完成年代、狀態、來源與對立候選審查前，這些資料只用於整理與缺口分析，不進入正式語義評分。現代遗存只作保存至今的比較對象，不能規定古人如何記錄；現代水流方向不得單獨否決候選。地圖待有效圖譜與 `palaeo-coast.json` 完成後重建。
