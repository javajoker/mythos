# F-0022：跨經同名山水總表（2026-10-27）

日期：2026-10-27。狀態：**已裁決（2026-10-27，項目負責人批准，逐項結案）**。來源：紅隊第一輪處置（`red-team-responses.md` zhongci B2/B3 ＋ beici B13 合併立項）。

## 總表規則（ADJ-005 前提修訂）

- **同名預設同一**；同經重名或屬性硬衝突者，必須**顯式裁決後方可拆分**。
- 中十一豐山同經兩見是書內硬反例——「山名同名唯一」作為絕對前提已死，但全盤放棄同名規則等於放棄最有用的跨卷連接工具，故修訂為上述裁決制。**豐山反例寫入 ADJ-005 作邊界案例（本次裁決正式確立）**。
- 滽滽之水是疊音專名，為類名規則的邊界試金石——疊音詞不太可能是性狀類名（類名多為單字性狀詞：赤/黑/弱/流沙）。本輪裁決其為**跨鏈共享同一水體**（與玄扈之水同例），說明疊音專名的跨經同現應優先考慮共享水體而非多實例。
