# ADJ-003：章尾山燭龍——極晝極夜與極光讀法裁決（2026-10-26）

- **狀態**：LLM 裁決 proposed，待項目發起人覆核。發起人指令：「大荒北章尾山燭龍指北方极昼极夜和极光的表现，以此找对应地理座标的范围。判断是否合理。」
- **對象**：章尾山燭龍（SHJ-17-1-032）與鍾山燭陰（SHJ-08-1-003）、西三鍾山（SHJ-02-3-004/005）的同名/同母題歸屬。

## 原文證據

- SHJ-17-1-032（大荒北）：「西北海外，赤水之北，有章尾山。有神，人面蛇身而赤，直目正乘，其暝乃晦，其視乃明，不食不寢不息，風雨是謁。是燭九陰，是謂燭龍。」
- SHJ-08-1-003（海外北）：「鍾山之神名曰燭陰，視為晝，瞑為夜，吹為冬，呼為夏，不飲，不食，不息，息為風，身長千里。在無啓之東。其為物，人面，蛇身，赤色，居鍾山下。」

## 讀法裁決（統一推論順序）

### 1. 現象讀法（人文風物層）

| 原文 | 極地光象對應 |
|---|---|
| 視為晝，瞑為夜／其暝乃晦，其視乃明 | **極晝極夜**——極圈內太陽數月不落/不升；「視/瞑」＝開眼為晝、閉眼為夜的年度節律人格化 |
| 吹為冬，呼為夏 | 季節風與寒暑交替（極地季風認知） |
| 人面蛇身而赤／身長千里 | **極光弧**——紅色蛇形光幕橫亘天際（低緯可見的極光多為紅色高層弧） |
| 直目正乘 | 極光直立光柱/射線（vertical rays）——「正乘」＝垂直矗立 |
| 是燭九陰 | 極光照亮極夜（「九陰」＝幽暗長夜之地——與北三「西望幽都」極北幽暗符號互證） |
| 不食不寢不息／風雨是謁 | 天象不依生物節律——天象級記錄 |

結論：燭龍/燭陰＝**極晝極夜＋極光的複合人格化**（高置信讀法，medium_high）。此讀法與「幽都」「雞號寒風」（北三錞于毋逢）構成同一極北認知簇。

### 2. 地理範圍推定

極晝極夜觀測要求緯度 ≥ 66.5°N（極圈）；紅色極光弧在太陽活動期可見於 55–65°N，常態極光帶 60–70°N。綜合取 **60–70°N**。

在北山經框架內的山系候選（同寬容規則）：

| 候選 | 座標範圍 | 評估 |
|---|---|---|
| **上揚斯克—切爾斯基山系** | 63–70°N, 130–150°E | 北三鏈路走廊正北延線（貝加爾→楚科奇中途）；緯度達極圈 ✓；主候選 |
| 普托拉納高原 | 66–70°N, 90–100°E | 北一/北二框架北延；台地「山」形 ✓；對立候選 |
| 楚科奇高地 | 64–68°N, 165–180°E | 北三終點區（錞于毋逢已承載終點錨）；對立候選 |
| 帕亞霍伊/新地島方向 | 66–70°N, 55–70°E | 偏西，離北山走廊遠；降級 |

**合理性判斷：合理**——「西北海外」在大荒北框架內指蒙古—西伯利亞以北；章尾山取 63–70°N 亞寒帶—極圈山系（上揚斯克—切爾斯基方向為主候選），pending_anchor（方向性，不編造精確坐標）。

### 3. 同名/同母題裁決

- **章尾山 ≠ 西三鍾山**（加沙—南黎凡特方向，31°N）：加沙無極晝極夜與極光 ✗——分立裁決（同名異實/同母題異山）。「燭陰居鍾山下」（海外北）之鍾山同屬北方框架，與西三鍾山亦分立。
- **章尾山燭龍 ↔ 海外北鍾山燭陰**：同一極地光象母題的兩處記錄（同母題；合併為一山 vs 兩山各記——保留雙讀待覆核）；與「九陰」（是燭九陰）互文支持同簇。
- 「赤水之北」之赤水：按 ADJ-005 類名規則為北方紅色水體類名實例（非紅海）——book17 原復用紅海讀法撤銷。

## 修訂（2026-10-27，紅隊處置 RT-B16）

紅隊審查指出本裁決的兩處缺陷，經項目負責人採納，修訂如下：

1. **循環依賴解除**：原裁決以「北三鏈路走廊正北延線」為章尾山定位依據，而北三終點（錞于毋逢=楚科奇）本身因單腿 18× 放大被里程否決（主候選已改外貝加爾方向）——章尾山與北鏈末端**脫鉤**，不再作為鏈路推論的支點。
2. **極光—極晝約束過強更正**：紅極光在磁暴期 40°N 可見（東亞史書「紅氣」記載可為證據層），切爾斯基主峰帶大部無極晝——「極晝極夜＋極光」雙約束不能鎖定單點。
3. **候選改為極圈帶區間**：章尾山候選改記為極圈帶（北地群島—泰梅爾—科拉半島皆可入冊），方位性、不編造精確坐標的原則維持；單列重審見 `F-0018-zhangwei-decouple.md`。

原「上揚斯克—切爾斯基山系為主候選」降為帶內候選之一，與其他極圈帶候選同權，待 F-0018 重審。
