# F-0009 現實山系表述勘測與中山經「從昆侖出發」結構

日期：2026-10-23。起因：發起人裁定「西山經從喜馬拉雅向唐古拉走；中山經應該有現實的昆侖山出發再走山脈轉折」，並要求尋找祁連山、太行山、秦嶺、橫斷山、現實昆侖山的**表述**（非名稱）進行錨定。

## 2. 西山經「從喜馬拉雅向唐古拉走」核查

v2 已自洽：西次二經＝喜馬拉雅南麓→印度河；西山經之首 v2＝川西→藏東→念青唐古拉（騩山/納木錯東緣）；大時之山＝巴顏喀拉分水嶺。**現實昆侖—巴顏喀拉—唐古拉軸**正好是西山經與中山經的分界軸：西山經在軸南（藏/喜馬拉雅南麓），中山經在軸北（黃河水系中原）。

## 3. 中山經「從昆侖出發」的分支結構（修正版）

```
總軸（西山經）：喜馬拉雅（西二）→ 橫斷山—藏東（西一）→ 巴顏喀拉—唐古拉
                          ║（山脈轉折：現實昆侖東延為秦嶺）
中山經（軸北，黃河水系）：
  出發鏈：中五（東昆侖阿尼瑪卿方向 → 沿黃河南岸東行 → 豫西—豫北）
  北支：中一（晉南中條—霍山—太行南段）
  中樞：中六（洛陽盆地西緣）→中七（嵩山方向三受水分水嶺）→中三（九水合流港山）
  中支南：中四（洛/伊雙受水）→中二（伊水上溯扇）
  南支：中八（鄂西北漳雎嵌套水系）→中十一（南陽盆地北緣雙流扇）→中十二（湖—九河格局）
  西南支：中九（大江東行走廊，接西山首經東端）
  孤短鏈：中十（東昆侖東北緣方向候選，310 里）
```

## 4. 適配順序調整（替代此前河洛優先序）

1. **中五**（昆侖出發鏈，東昆侖起點候選——里程擬合帶頂 96%）——中山經的總起點
2. 中七（三受水分水嶺拓撲錨）→ 3. 中六 → 4. 中三（中樞群）
5. 中四 → 6. 中二（秦嶺東段方向）
7. 中一（北支，注意其自記 6,670 vs 腿程 937 的層累 variant）
8. 中九（西南支；三星堆評估；接西山首經東端）
9. 中八 → 10. 中十一 → 11. 中十二（南支）
12. 中十（孤短鏈）

依賴：中五的東昆侖起點為候選錨（未確認，屬性中強）；中七拓撲錨與中五互相校準；其餘沿已校準尺度展開。
